# Online Exams Screenshot Mockups

This directory contains visual mockups and screenshot placeholders for the online exams documentation.

## Purpose

These images help users visualize the online exam interface and workflows without needing actual screenshots from the live system.

## Files Needed

## Mockup Guidelines

**Style:**
- Use 4SCH brand colors
- Keep designs clean and simple
- Ensure text is readable
- Use realistic but sample data
- Maintain consistent UI elements

**Format:**
- SVG for scalability
- PNG fallback for complex mockups
- Optimize file sizes

**Content:**
- Use placeholder names (John Doe, Jane Smith)
- Sample questions from various subjects
- Realistic but generic data
- Avoid real student information

## Usage in Documentation

Reference these images in markdown:

```markdown
![Teacher creating an exam](/img/screens/online-exams/teacher-create-exam.svg)
```
