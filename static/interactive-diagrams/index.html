How to Use These Diagrams

Navigate: Each diagram has multiple tabs showing different workflows. Click tabs or use arrow keys to switch views.

Interact: All diagrams are fully keyboard accessible. Use Tab to navigate, Enter to activate, and arrow keys for tab navigation.

Print: Use your browser's print function (Ctrl+P / Cmd+P) to print any diagram. The print layout is optimized to show all workflows.

Accessibility: All diagrams include ARIA labels and screen reader support. Use a skip link to jump to main content.
