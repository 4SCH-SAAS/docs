## 👔 For Administrators

### Quick Exam Creation Workflow

**4 Steps to Launch:**
1. **Create Exam** → Exams → Offline Exams → Create
2. **Add Timetable** → Select subjects, set dates/times
3. **Monitor Mark Entry** → Track teacher progress
4. **Publish Results** → Make visible to students

### Essential Fields

**Creating Exam:**
- Exam Name (e.g., "Mid-Term Exam March 2025")
- Class
- Session Year
- Start Date
- End Date
- Publish Status (No initially)

**Creating Timetable (per subject):**
- Subject
- Date
- Start Time
- End Time
- Total Marks
- Passing Marks

### Quick Actions

| Action | Location | Time |
|--------|----------|------|
| Create Exam | Exams → Offline Exams → Create | 2-3 min |
| Add Timetable | Open Exam → Create Timetable | 5-10 min |
| View Results | Open Exam → View Results | Instant |
| Publish Results | Open Exam → Publish | 30 sec |
| Export Results | Results → Export | 1-2 min |

### Common Tasks

**Check Exam Status:**
```
Upcoming (0) - Before start date
Ongoing (1) - Between start and end date
Completed (2) - After end date
```

**Mark Entry Progress:**
- Open exam → View marks entered by subject
- Follow up with teachers for missing marks

**Result Publication:**
- ✅ All marks entered → Publish
- ❌ Missing marks → Cannot publish
- 🔄 Need corrections → Unpublish, edit, republish

## 👨‍🏫 For Teachers

### Mark Entry - Quick Steps

**3 Steps:**
1. **Navigate** → Exams → Mark Entry
2. **Select** → Choose exam and your subject
3. **Enter** → Type marks for each student, Save

### Mark Entry Fields

| Field | Description |
|-------|-------------|
| **Roll Number** | Student identification |
| **Student Name** | Full name |
| **Obtained Marks** | Enter marks (0 to total marks) |
| **Pass/Fail** | Auto-calculated |
| **Grade** | Auto-assigned |
| **Comments** | Optional teacher notes |

### Validation Rules

✅ **Valid:**
- Marks between 0 and total marks
- Numeric values only
- Decimal marks (if allowed)

❌ **Invalid:**
- Marks exceeding total
- Negative numbers
- Non-numeric values

### Common Commands

| What You Want | How to Do It |
|---------------|--------------|
| View timetable | Exams → Exam Timetable |
| Enter marks | Exams → Mark Entry → Select exam/subject |
| Edit marks | Return to mark entry, modify, save |
| View results | Exams → View Results → Select exam |
| Check passing status | Results show pass/fail per subject |

### Time Management

**Recommended Timeline:**
- Conduct exam: Day 1
- Evaluate papers: Days 2-7
- Enter marks: Within 1-2 weeks
- Results published: 2-4 weeks total

### Quick Tips

✅ Enter marks promptly (within 1 week)  
✅ Double-check before saving  
✅ Use Tab key for quick navigation  
✅ Note absences clearly  
✅ Review for data entry errors

- Grade
- Teacher comments

### Understanding Results

**Pass/Fail Logic:**
```
Subject Level:
Pass = Obtained marks ≥ Passing marks
Fail = Obtained marks < Passing marks

Overall:
Pass = Passed in ALL subjects
Fail = Failed in ANY subject
```

**Typical Grade Scale:**
- A+ = 90-100%
- A = 80-89%
- B = 70-79%
- C = 60-69%
- D = 50-59%
- E = 35-49%
- F = Below 35% (Fail)

## 📊 Exam Status Reference

### Status Indicators

| Status | Code | Meaning | Student View |
|--------|------|---------|--------------|
| **Upcoming** | 0 | Before start date | 🔵 Blue badge |
| **Ongoing** | 1 | Between start-end date | 🟢 Green badge |
| **Completed** | 2 | After end date | ⚪ Grey badge |

### What Status Means

**Upcoming:**
- Timetable available for viewing
- Students can prepare
- Results not yet available
- Marks not entered

**Ongoing:**
- Exams in progress
- Students taking papers
- Teachers evaluating
- Marks being entered

**Completed:**
- All exams finished
- Teachers entering marks
- Results pending publication
- Or results already published

```
1. Select exam → Select subject
```

- Edit previous marks

## 🎓 Grade Calculation

### Percentage Formula

```
Subject Percentage = (Obtained Marks / Total Marks) × 100

Overall Percentage = (Total Obtained / Total Possible) × 100
```

### Example Calculation

**Student: John Doe**
```
Mathematics: 75/100 = 75%
English: 65/80 = 81.25%
Science: 80/100 = 80%
Social: 55/80 = 68.75%

Total: 275/360 = 76.39% → Grade A
```

### Grade Assignment

**Based on percentage ranges:**
```
90-100% → A+
80-89%  → A
70-79%  → B
60-69%  → C
50-59%  → D
35-49%  → E
0-34%   → F (Fail)
```

:::note School-Specific
Grade ranges may vary by school. Check with your school administration.
:::
