## 📊 Comparison Guide

### Online vs Offline Exams

| Feature | Online Exams | Offline Exams |
|---------|--------------|---------------|
| **Format** | Digital (MCQ) | Paper-based |
| **Question Types** | Multiple choice only | Any (essay, practical, MCQ) |
| **Grading** | Automatic | Manual by teachers |
| **Results** | Instant | After evaluation |
| **Use Cases** | Quizzes, tests, assessments | Major exams, essays, practicals |
| **Student Access** | Mobile app & web portal | Exam hall |
| **Security** | Exam key required | Physical invigilation |
| **Attempts** | One-time only | One-time only |
| **Best For** | Objective knowledge testing | Deep understanding assessment |

**When to Use What:**
- **Weekly/Monthly Tests:** Online exams for quick feedback
- **Mid-Term/Finals:** Offline exams for comprehensive assessment
- **Both:** Use strategically throughout the academic year

**Learn More:** [Read: Online vs Offline Exam Comparison](https://github.com/4SCH-SAAS/docs/blob/main/video-tutorials/scripts/03-feature-deep-dives/14-exam-system-comparison.md)

## 💡 Quick Tips

### For Maximum Efficiency

**Administrators:**
- Build question banks during off-peak times
- Schedule exam timetables 2-3 weeks in advance
- Export results regularly as backups
- Review analytics to identify system improvements

**Teachers:**
- Create questions while teaching topics (not before exams)
- Use random assignment for varied tests
- Enter marks within one week of exam completion
- Use templates for recurring exam structures

**Students:**
- Check timetables early and plan study time
- For online exams: test internet connection beforehand
- Review results to identify weak areas
- Ask teachers for clarification promptly

**Parents:**
- Enable notifications for exam announcements
- Create supportive study environment at home
- Review results constructively with children
- Communicate with teachers proactively
