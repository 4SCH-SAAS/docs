## 👨‍🏫 TEACHERS - QUICK GUIDE

### Creating an Exam - 4 Steps

**1. Navigate**
- Exams → Online Exams → Create

**2. Fill Details**
- Title (clear, descriptive)
- Class & Section(s)
- Subject
- Start Date & Time
- End Date & Time
- Duration (minutes)
- Exam Key (6 digits)

**3. Add Questions**
- Select from bank
- Create new
- Random assignment

**4. Review & Publish**
- Check question count
- Verify total marks
- Announce to students

### Time Planning

| Questions | Duration | Minutes/Question |
|-----------|----------|------------------|
| 10 | 15-20 min | 1.5-2 min |
| 20 | 30-40 min | 1.5-2 min |
| 30 | 45-60 min | 1.5-2 min |
| 50 | 75-100 min | 1.5-2 min |

### DO's and DON'Ts

✅ **DO:**
- Build question banks early
- Test with dummy exam first
- Mix difficulty levels
- Share exam key at exam time only

❌ **DON'T:**
- Share exam key days early
- Create questions night before
- Set unrealistic time limits
- Edit after students start

## 👨‍🎓 STUDENTS - QUICK GUIDE

### Before Starting
- [ ] Stable internet (WiFi preferred)
- [ ] Fully charged device (100%)
- [ ] Quiet environment
- [ ] Exam key ready
- [ ] Full exam duration available

### Taking the Exam - 6 Steps

**1. Access**
- Mobile: Exams tab → Online Exams
- Web: ngs.4sch.com → Exams → Online Exams

**2. Find Exam**
- Look for "Ongoing" status (green)

**3. Enter Key**
- Type 6-digit exam key (no spaces)

**4. Answer Questions**
- Single answer: Select ONE ○
- Multiple answer: Select ALL correct ☑

**5. Watch Timer**
- Keep track of remaining time
- Red timer = running low!

**6. Submit**
- Review answers if time allows
- Click Submit before time expires

### Important Rules

⚠️ **ONE attempt only** - You cannot retake  
⏰ **Auto-submit** - Exam submits when time expires  
✅ **All or nothing** - Multiple choice needs ALL correct  
📵 **Stay focused** - Don't switch apps  

### Answer Selection

**Single Answer (○):**
```
○ Option A
● Option B ← Select ONE only
○ Option C
```

**Multiple Answer (☑):**
```
☑ Option A ← Select ALL correct
☐ Option B
☑ Option C ← Must get all to earn marks
```

## 📊 GRADING SYSTEM

### How Marks Work

**Single Answer Question (5 marks):**
- ✓ Correct answer selected = **5 marks**
- ✗ Wrong answer selected = **0 marks**
- ✗ No answer = **0 marks**

**Multiple Answer Question (10 marks):**
- ✓ ALL correct + NO wrong = **10 marks**
- ✗ Some correct, some missing = **0 marks**
- ✗ All correct + any wrong = **0 marks**
- ✗ No answer = **0 marks**

### Formula

```
Obtained Marks = Sum of correct answer marks
Total Marks = Sum of all question marks
Percentage = (Obtained / Total) × 100
```

### Example

**Exam:** 20 questions
- Q1-10: 2 marks each = 20 marks
- Q11-20: 3 marks each = 30 marks
- **Total: 50 marks**

**Student scores:**
- Q1-8: Correct = 16 marks
- Q9-10: Wrong = 0 marks
- Q11-18: Correct = 24 marks
- Q19-20: Wrong = 0 marks
- **Obtained: 40 marks**

**Result:** 40/50 = **80%**
