## 👨‍🏫 For Teachers

### Creating an Exam - Quick Steps

1. **Navigate:** Exams → Online Exams → Create
2. **Fill Details:**
   - Title (clear, descriptive)
   - Class & Section(s)
   - Subject
   - Start Date & Time
   - End Date & Time
   - Duration (in minutes)
   - Exam Key (6 digits)
3. **Add Questions:** Choose from bank, create new, or random
4. **Review & Publish**

### Question Creation Shortcuts

| Question Type | How to Create | Marks Assignment |
|---------------|---------------|------------------|
| **Single Answer** | Add 2-6 options, check ONE correct | Set marks per question |
| **Multiple Answer** | Add 2-6 options, check MULTIPLE correct | Set marks per question |
| **With Image** | Upload image after entering question text | Same as above |

### Time Planning Guide

| Exam Length | Suggested Duration | Questions per Minute |
|-------------|-------------------|---------------------|
| 10 questions | 15-20 minutes | 1.5-2 min/question |
| 20 questions | 30-40 minutes | 1.5-2 min/question |
| 30 questions | 45-60 minutes | 1.5-2 min/question |
| 50 questions | 75-100 minutes | 1.5-2 min/question |

### Common Commands

| What You Want | How to Do It |
|---------------|--------------|
| Edit exam before students start | Find exam → Edit icon |
| Add more questions | Open exam → Add Questions |
| Remove a question | Open exam → Question list → Remove |
| View who attempted | Open exam → Results |
| Download results | Results view → Export button |
| Delete exam | Find exam → Delete (only if no attempts) |

### Best Practice Reminders

✅ Build question banks BEFORE creating exams  
✅ Test with a dummy exam first  
✅ Set realistic time limits (1.5-2 min/question)  
✅ Share exam key ONLY when exam starts  
✅ Mix difficulty levels (easy, medium, hard)  
✅ Review questions for clarity and accuracy

## 👨‍🎓 For Students

### Taking an Exam - Quick Guide

**Before You Start:**
1. ✓ Stable internet connection (Wi-Fi preferred)
2. ✓ Fully charged device
3. ✓ Quiet environment
4. ✓ Have exam key ready
5. ✓ Know exam duration

**During the Exam:**
1. Enter 6-digit exam key
2. Read each question carefully
3. Select answer(s)
4. Navigate: Next/Previous buttons
5. Watch the timer
6. Submit before time expires

**After Submission:**
- View your results immediately
- Check marks obtained / total marks
- Note your percentage
- Review performance (if allowed)

### Quick Troubleshooting

| Problem | Quick Fix |
|---------|-----------|
| Invalid Exam Key | Verify with teacher, try again |
| Exam won't load | Refresh page/app, check internet |
| Timer not showing | Continue answering, note start time |
| Lost connection | Reconnect quickly, refresh page |
| Can't submit | Check internet, try again, wait 30 sec |

### Exam Key Rules

🔑 **Do:**
- Get key from teacher before exam time
- Enter exactly as given (6 digits)
- Keep it confidential

🔑 **Don't:**
- Share with others before exam
- Add spaces or extra characters
- Use old/expired keys

### Answer Selection Guide

**Single Answer (Radio Buttons ○):**
```
○ Option A
● Option B ← Select ONE only
○ Option C
○ Option D
```

**Multiple Answer (Checkboxes ☑):**
```
☑ Option A ← Can select multiple
☐ Option B
☑ Option C ← Must select ALL correct
☐ Option D
```

### Time Management Tips

| Time Remaining | What to Do |
|----------------|------------|
| **75-100%** | Work steadily, read carefully |
| **50-75%** | Maintain pace, skip hard questions |
| **25-50%** | Speed up, return to skipped questions |
| **10-25%** | Answer all remaining, make educated guesses |
| **< 10%** | Submit immediately after final review |

### Important Reminders

⚠️ **ONE attempt only** - You cannot retake the exam  
⏰ **Auto-submit** - Exam submits automatically when time expires  
✅ **All or nothing** - For multiple-choice, select ALL correct answers  
📵 **Stay focused** - Avoid switching apps/tabs  
💾 **Auto-save** - Your answers are saved as you go

## 📊 Grading System Quick Reference

### How Marks Are Calculated

```
Single Answer Question (5 marks):
✓ Correct answer selected = 5 marks
✗ Wrong answer selected = 0 marks
✗ No answer selected = 0 marks

Multiple Answer Question (10 marks):
✓ ALL correct selected, NO wrong = 10 marks
✗ Some correct, some missing = 0 marks
✗ All correct + any wrong = 0 marks
✗ No answer selected = 0 marks
```

### Grading Formula

```
Obtained Marks = Sum of marks from correct answers
Total Marks = Sum of marks from all questions
Percentage = (Obtained Marks / Total Marks) × 100
```

### Example Calculation

```
Exam with 20 questions:
- Questions 1-10: 2 marks each = 20 marks
- Questions 11-20: 3 marks each = 30 marks
Total Marks = 50

Student scores:
- Questions 1-8: Correct = 16 marks
- Questions 9-10: Wrong = 0 marks
- Questions 11-18: Correct = 24 marks
- Questions 19-20: Wrong = 0 marks
Obtained Marks = 40

Percentage = (40 / 50) × 100 = 80%
```

## 📱 Platform-Specific Tips

### Mobile App

**Android:**
- Disable notifications during exam
- Use Do Not Disturb mode
- Close other apps to free memory
- Ensure stable connection (WiFi preferred)

**iOS:**
- Enable Guided Access (Settings → Accessibility)
- Disable notifications
- Close background apps
- Keep device plugged in if battery < 50%

### Web Portal

**Recommended Browsers:**
- Chrome 90+ (Best performance)
- Firefox 88+
- Safari 14+
- Edge 90+

**Browser Tips:**
- Close unnecessary tabs
- Clear cache before important exams
- Disable browser extensions
- Allow pop-ups for 4SCH domain
