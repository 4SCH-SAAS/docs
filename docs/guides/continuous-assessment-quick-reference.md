# Continuous Assessment Quick Reference

A one-page cheat sheet for teachers entering CA marks. Print this and keep
near your computer for daily reference.

> **Full guide:** [Continuous Assessment Guide](./continuous-assessment.md) and
> [CA on Mobile Apps](./continuous-assessment-mobile.md)

---

## At a Glance

| What | Where |
|---|---|
| **Configure CA types** | Web → Exams → Manage Exam → Configure CA (admin only) |
| **Enter CA marks (web)** | Web → Exams → Manage Exam Marks |
| **Enter CA marks (mobile)** | Teacher app → Academics → Offline Exam Result |
| **View CA results** | Parent/Student app → Exams → Results → tap subject |

---

## Web: Entering CA Marks

```text
1. Login as Teacher
2. Click: Exams → Manage Exam Marks
3. Choose: Class Section → Exam → Subject
4. Select: Assessment Type (CA1 / CA2 / Exam)
5. Click: Search
6. Enter marks for each student (must be ≤ Total Marks shown)
7. Click: Save as Draft (editable) or Submit & Publish (final)
```

---

## Mobile (Teacher App): Entering CA Marks

```text
1. Open: Staff Teacher app
2. Tap: Academics → Offline Exam Result
3. Select: Class Section → Exam → Subject
4. Tap: Assessment Type dropdown → select CA1 / CA2 / Exam
5. Enter marks for each student
6. Tap: Save as Draft or Submit & Publish
```

---

## CA Type Quick Reference

| CA Type | Typical Weightage | Typical Max Marks |
|---|---|---|
| **CA1** | 20% | 20 |
| **CA2** | 20% | 20 |
| **CA3** (optional) | 10% | 10 |
| **CA4** (optional) | 10% | 10 |
| **CA5** (optional) | — | — |
| **Exam** | 60% | 60 |
| **Total** | **100%** | **100** |

> Actual weightages vary per school/exam — check the dropdown for your max.

---

## Validation Rules

- ✅ Marks must be **0 to Total Marks** (e.g., 0-20 for CA1 at 20%)
- ✅ Empty fields trigger error: "Please add marks to all students"
- ✅ Non-numeric values rejected
- ✅ Each CA type stored independently — switching doesn't affect others

---

## Save Draft vs Submit & Publish

| Action | Effect | When to Use |
|---|---|---|
| **Save as Draft** | Marks saved but editable | While entering, before reviewing |
| **Submit & Publish** | Marks finalised; cannot edit | After all marks verified |

> Drafts can be re-saved any time. Publishing requires admin to unpublish if changes needed later.

---

## Switching Between CA Types

When you switch the Assessment Type dropdown:

- ✅ The marks table reloads with the new CA's data
- ✅ Total Marks header updates to the new CA's max
- ✅ Previously saved CA marks are **preserved** (not deleted)
- ✅ You can enter CA1 today and CA2 next week

---

## Symbols to Watch For

| Symbol | Meaning | What to Do |
|---|---|---|
| ⚠️ **Needs Review** | Mark was auto-adjusted by the system | Verify the value and save to confirm |
| 📝 Draft | Marks saved but not published | Submit when ready |
| ✅ Published | Final and visible to students/parents | Cannot edit (admin must unpublish) |

## Common Mistakes & Fixes

| Mistake | Fix |
|---|---|
| **"No CA dropdown showing"** | Exam doesn't have CA configured. Ask admin to configure it. |
| **"Marks exceed total"** | Reduce mark; max is shown next to input. |
| **"Marks won't save"** | Check internet; refresh and re-enter if needed. |
| **"Wrong total marks shown"** | Switch CA type and back — refreshes correctly. |

---

## Pro Tips

- ⌨️ **Use Tab key** to jump between mark inputs faster
- 💾 **Save Draft frequently** — protects against connection drops
- 📊 **Review CA breakdown** before publishing — catches typos early
- 📱 **Mobile is faster for small classes** (<10 students)
- 🖥️ **Web is faster for large classes** (bulk entry, copy-paste from spreadsheet)
- 🔁 **Enter CAs in order** (CA1 → CA2 → Exam) but order isn't enforced

---

## After Publishing

Once published, the result becomes visible to:

- Students (in their mobile app and web portal)
- Parents/Guardians (in their mobile app)
- Listed in PDF report cards
- Aggregated into term totals and rankings

Students/parents will receive a push notification automatically.

---

## Need to Edit Published Marks?

1. Ask the **School Admin** to unpublish the exam
2. Edit the marks as normal
3. Admin re-publishes when ready
4. Students/parents get a new notification
