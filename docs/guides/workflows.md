## Starting a New Academic Term {#starting-a-new-term}

This workflow covers everything needed to start a new term smoothly.

### Timeline: 2 Weeks Before Term Starts

**Week 1: Admin Preparation**

**Day 1-2: Academic Setup**
1. ✅ **Create the new term** (if not already created)
   - Go to **Settings** → **Academic** → **Sessions**
   - Add new term with start and end dates
   - Set as "Active Term"

2. ✅ **Verify class structures**
   - Check all classes have sections assigned
   - Verify class teachers are assigned
   - Update if staff changes occurred

3. ✅ **Review and update subjects**
   - Add any new subjects
   - Remove discontinued subjects
   - Verify subject-to-class assignments

**Day 3-4: Staff Assignments**
1. ✅ **Assign teachers to subjects**
   - Go to **Academic** → **Teacher Assignments**
   - Assign each teacher to their classes and subjects
   - Verify no conflicts (teacher teaching two classes at same time)

2. ✅ **Create/update timetables**
   - Go to **Timetable** → **Create Timetable**
   - Build timetable for each class
   - Check for room and teacher conflicts
   - Publish timetables

**Day 5: Finance Setup**
1. ✅ **Review fee structures**
   - Check if fees have changed for new term
   - Update fee structures if needed

2. ✅ **Generate fee invoices**
   - Go to **Finance** → **Generate Invoices**
   - Select all classes
   - Set due date (typically 2 weeks into term)
   - Generate invoices

3. ✅ **Send fee notifications**
   - System automatically notifies parents
   - Or manually send via **Messaging** → **Fee Reminder**

**Week 2: Communication & Final Checks**

**Day 6-7: Communication**
1. ✅ **Send welcome back message**
   - Go to **Messaging** → **New Announcement**
   - Write welcome message with:
     - Term start date
     - Important dates (holidays, exams)
     - Any new policies
   - Send to all parents, students, and staff

2. ✅ **Share timetables**
   - Ensure timetables are published
   - Students and teachers can now view their schedules

**Day 8-10: Staff Training**
1. ✅ **Brief teachers on any system updates**
2. ✅ **Remind them of expectations:**
   - Mark attendance daily
   - Enter grades promptly
   - Respond to parent messages within 24 hours

**Day 11-14: Final Checks**
1. ✅ **Verify all students are enrolled** in correct classes
2. ✅ **Check parent accounts** are active and linked
3. ✅ **Test online fee payment** (if enabled)
4. ✅ **Prepare first day attendance** sheets as backup

### First Day of Term

**Morning Tasks:**
1. ✅ Monitor attendance marking by teachers
2. ✅ Address any login issues for staff, students, or parents
3. ✅ Check that fee invoices are visible to parents

**End of Day:**
1. ✅ Review attendance completion rate
2. ✅ Follow up with teachers who haven't marked attendance
3. ✅ Send summary report to school leadership

### First Week Monitoring

**Daily:**
- Check attendance completion
- Monitor fee payments
- Respond to technical issues

**End of Week:**
- Generate attendance report
- Generate fee collection report
- Address any outstanding issues

## Publishing Term Results {#publishing-results}

This workflow covers the complete process of publishing grades and report cards at the end of term.

### Timeline: 2 Weeks Before Term Ends

**Week 1: Grade Entry**

**Days 1-7: Teachers Enter Grades**
1. ✅ **Admin sends reminder to all teachers**
   - Go to **Messaging** → **New Message**
   - Message all teachers: "Please enter all grades by [date]"
   - Include deadline (typically 1 week before term ends)

2. ✅ **Teachers enter final exam scores**
   - Teachers go to **Gradebook**
   - Enter scores for final exams
   - Save as draft (don't publish yet)

3. ✅ **Admin monitors grade entry progress**
   - Go to **Reports** → **Grade Entry Status**
   - See which teachers haven't completed entries
   - Send individual reminders to those behind

**Day 7: Admin Review**
1. ✅ **Check for missing grades**
   - Go to **Gradebook** → **Missing Grades Report**
   - Identify students with incomplete grades
   - Contact relevant teachers

2. ✅ **Check for unusual grades**
   - Look for scores of 0 (might be data entry error)
   - Look for scores over 100 (invalid)
   - Flag suspicious patterns

**Week 2: Report Card Preparation**

**Day 8-9: Class Teacher Comments**
1. ✅ **Admin reminds class teachers** to write comments
2. ✅ **Class teachers write student comments**
   - Go to **Students** → Select class
   - For each student, write general comment about:
     - Academic performance
     - Behavior and attitude
     - Areas for improvement
     - Encouragement

**Example Comments:**
- "John has shown excellent improvement in Mathematics this term. Encourage him to continue his hard work."
- "Mary is a bright student but needs to improve attendance. Her absences are affecting her performance."
- "David is a diligent student with good behavior. Keep up the good work!"

**Day 10: Principal's Approval**
1. ✅ **Admin generates draft report cards**
   - Go to **Reports** → **Report Cards** → **Generate Drafts**
   - Review a sample from each class

2. ✅ **Principal reviews and approves**
   - Check for errors
   - Verify grading is fair and consistent
   - Approve for publishing

**Day 11: Grade Publishing**
1. ✅ **Admin publishes all grades**
   - Go to **Gradebook** → **Publish Grades**
   - Select all classes
   - Confirm publishing

2. ✅ **System actions:**
   - Grades become visible to students and parents
   - Parents receive notification
   - Report cards become downloadable

**Day 12-14: Report Card Distribution**

**Digital Distribution:**
1. ✅ **Send announcement**
   - Inform parents that report cards are available
   - Provide instructions to download

2. ✅ **Parents download report cards**
   - Go to **Grades** → **Download Report Card**
   - Save as PDF

**Physical Distribution (if required):**
1. ✅ **Print report cards**
   - Admin prints all report cards
   - Sort by class

2. ✅ **Distribute on last day**
   - Class teachers give to students
   - Or parent collection at designated time

### Post-Publishing Tasks

**Week After Term Ends:**
1. ✅ **Monitor parent feedback**
   - Address questions about grades
   - Correct any genuine errors (rare, needs admin approval)

2. ✅ **Generate analytics reports**
   - Class performance analysis
   - Pass/fail rates
   - Subject-wise performance
   - Share with leadership team

3. ✅ **Archive term data**
   - System automatically archives
   - Ensure backup is complete

## Fee Collection Lifecycle {#fee-collection}

This workflow covers the complete fee collection process from invoice generation to payment reconciliation.

### Phase 1: Invoice Generation (Start of Term)

**Admin Tasks:**
1. ✅ **Generate invoices for all students**
   - Go to **Finance** → **Generate Invoices**
   - Select current term
   - Select all classes (or specific classes)
   - Set due date
   - Click **Generate**

2. ✅ **Review generated invoices**
   - Check a few random invoices for accuracy
   - Verify concessions are applied correctly
   - Verify amounts match fee structure

3. ✅ **System sends notifications**
   - Parents receive email/SMS about fees due
   - Parents can view invoice in their portal

### Phase 2: Payment Collection (Ongoing)

**Online Payments:**
1. ✅ **Parent logs in to portal**
2. ✅ **Views outstanding invoices**
3. ✅ **Clicks "Pay Now"**
4. ✅ **Selects payment method:**
   - Card payment
   - Bank transfer
   - Mobile money (M-Pesa, MTN, etc.)
5. ✅ **Completes payment**
6. ✅ **System actions:**
   - Marks invoice as paid
   - Generates receipt
   - Sends receipt to parent via email/SMS
   - Updates fee collection reports

**Offline Payments (Cash/Bank Transfer):**
1. ✅ **Parent pays at school office or bank**
2. ✅ **Office staff records payment:**
   - Go to **Finance** → **Record Payment**
   - Search for student
   - Select invoice
   - Enter amount, date, payment method
   - Enter receipt number
   - Click **Record**
3. ✅ **System actions:**
   - Marks invoice as paid
   - Generates digital receipt
   - Sends notification to parent

### Phase 3: Monitoring & Follow-Up

**Weekly Review (Admin Tasks):**
1. ✅ **Check collection rate**
   - Go to **Reports** → **Fee Collection Summary**
   - View percentage collected vs. expected

2. ✅ **Identify defaulters**
   - Go to **Finance** → **Outstanding Fees**
   - Filter by "Overdue"
   - Export list

3. ✅ **Send reminders**
   - Select students with overdue fees
   - Click **Send Reminder**
   - Customize message if needed

**Sample Reminder Message:**
> "Dear Parent,
>
> This is a friendly reminder that fees for [Term Name] are now overdue. The outstanding amount is [Amount].
>
> Please make payment at your earliest convenience to avoid any disruption to your child's studies.
>
> If you've already paid, please contact the school office with your payment reference.
>
> Thank you."

### Phase 4: Partial Payments

**When Parents Pay in Installments:**
1. ✅ **Parent pays first installment**
   - Admin records partial payment
   - System shows remaining balance

2. ✅ **Admin can set up payment plan** (optional)
   - Go to student's finance section
   - Set up installment schedule:
     - First installment: ₦50,000 by Jan 15
     - Second installment: ₦45,000 by Feb 15
   - System sends reminders for each installment

3. ✅ **Track installments**
   - Go to **Finance** → **Payment Plans**
   - Monitor who's keeping up with payments
   - Follow up with those falling behind

### Phase 5: Reconciliation (End of Term)

**Final Week Tasks:**
1. ✅ **Generate final collection report**
   - Go to **Reports** → **Finance** → **Term Collection Report**
   - Shows:
     - Total fees expected
     - Total collected
     - Outstanding amount
     - Collection percentage by class

2. ✅ **Reconcile bank statements**
   - Match bank deposits with recorded payments
   - Investigate discrepancies

3. ✅ **Handle edge cases:**
   - **Overpayments:** Carry forward to next term
   - **Write-offs:** Admin can write off uncollectible fees (with authorization)
   - **Refunds:** Process for withdrawn students

4. ✅ **Share report with leadership**
   - Email report to principal/school owner
   - Highlight collection rate and challenges

### Dealing with Chronic Non-Payment

**Escalation Process:**

**Week 1 After Due Date:**
- Friendly reminder via SMS/email

**Week 2:**
- Follow-up message
- Request parent to contact school office

**Week 3:**
- Phone call from admin
- Discuss payment challenges
- Offer payment plan if appropriate

**Week 4:**
- Official letter/email
- Warning about possible consequences

**Week 5+:**
- Meet with parent in person
- Involve school leadership
- Follow school policy (may include restriction from exams, etc.)

:::note Important
Always approach fee collection with empathy. Some parents face genuine financial hardship. Work with them to find solutions rather than immediately taking harsh actions.
:::

## Admitting a New Student {#new-student-admission}

This workflow covers the complete process of admitting a new student mid-term or at the start of a new session.

### Step 1: Initial Inquiry

**When Parent Visits/Calls:**
1. ✅ **Collect basic information:**
   - Child's name and age
   - Current school (if transferring)
   - Desired class/grade
   - Contact information

2. ✅ **Provide information:**
   - Available spaces in the class
   - Fee structure
   - School policies
   - Required documents

3. ✅ **Schedule admission test** (if applicable)
   - Set date and time
   - Inform parent what child should prepare

### Step 2: Admission Test & Interview

**Test Day:**
1. ✅ **Student takes placement test**
   - Appropriate to their grade level
   - Covers key subjects (Math, English)

2. ✅ **Parent interview** (if required)
   - Discuss expectations
   - Review school policies
   - Answer questions

3. ✅ **Review test results**
   - Determine appropriate class placement
   - Inform parent of decision

### Step 3: Documentation

**Required Documents (typical):**
- ✅ Birth certificate or age declaration
- ✅ Previous school report card
- ✅ Transfer certificate (if coming from another school)
- ✅ Passport photographs (2-4 copies)
- ✅ Medical record/immunization card
- ✅ Parent/guardian ID
- ✅ Proof of address

**Admin Verifies:**
- Documents are authentic
- All required documents are provided
- Information is consistent

### Step 4: Enrollment in 4SCH

**Admin Tasks:**
1. ✅ **Create student profile**
   - Go to **Students** → **Add Student**
   - Fill in all required information:
     - Personal details
     - Class assignment
     - Parent/guardian information
     - Emergency contacts
     - Medical information

2. ✅ **Upload documents**
   - Go to student profile → **Documents**
   - Upload scanned copies of all documents

3. ✅ **Generate admission number**
   - System auto-generates or admin assigns
   - Format example: "2024/0456"

4. ✅ **Create parent account**
   - Usually automatic when student is created
   - Verify parent receives login credentials

### Step 5: Fee Payment

**Fee Assessment:**
1. ✅ **Calculate fees for new student**
   - If joining mid-term, may be prorated
   - Include any registration/admission fees
   - Include uniform, books if applicable

2. ✅ **Generate invoice**
   - Go to **Finance** → **Create Invoice**
   - Add all fee items
   - Set due date

3. ✅ **Parent makes initial payment**
   - Full payment or agreed deposit
   - Admin records payment in system

4. ✅ **Issue receipt**
   - System generates receipt
   - Print or send digitally to parent

### Step 6: Orientation

**Before First Day:**
1. ✅ **Provide orientation pack:**
   - School handbook
   - Timetable
   - Class list and teachers
   - School map
   - Uniform requirements
   - School calendar

2. ✅ **Introduce to class teacher**
   - Email or message class teacher about new student
   - Provide relevant information (medical, special needs, etc.)

**First Day:**
1. ✅ **Class teacher welcomes student**
   - Introduces to classmates
   - Assigns seat
   - Provides textbooks/materials

2. ✅ **Admin checks in**
   - Verify student attended
   - Check if parent has questions
   - Ensure system access is working

### Step 7: Follow-Up

**First Week:**
1. ✅ **Teacher marks attendance** (student should now appear in class list)
2. ✅ **Monitor adjustment**
   - Check with class teacher on how student is settling
   - Address any concerns promptly

**First Month:**
1. ✅ **Review performance**
   - Check first assessment scores
   - Verify placement was appropriate
   - Consider remedial support if struggling

## Handling Student Transfers {#student-transfers}

When a student transfers to another school, follow this workflow.

### Step 1: Transfer Request

**When Parent Requests Transfer:**
1. ✅ **Admin receives request**
   - Parent submits written request
   - States reason for transfer
   - Provides new school information (if known)

2. ✅ **Check fee status**
   - Go to student's finance section
   - Verify all fees are paid
   - If outstanding, request payment before processing

3. ✅ **Check for school property**
   - Library books
   - Textbooks
   - Sports equipment
   - Lab equipment
   - Ensure all are returned

### Step 2: Documentation Preparation

**Admin Prepares:**
1. ✅ **Transfer Certificate**
   - Official document stating:
     - Student's full name
     - Admission number
     - Duration at school
     - Class level attained
     - Conduct and character
     - Reason for leaving
   - Signed by principal

2. ✅ **Academic Transcript**
   - Complete record of grades
   - All terms attended
   - Download from **Reports** → **Student Transcript**

3. ✅ **School Leaving Certificate**
   - Official school letterhead
   - States student is free to join another school

### Step 3: System Processing

**In 4SCH:**
1. ✅ **Go to student profile**
2. ✅ **Click "Withdraw Student"**
3. ✅ **Fill in:**
   - Withdrawal date
   - Reason: Transfer
   - New school name (if known)
   - Any additional notes

4. ✅ **Click "Process Withdrawal"**

**System Actions:**
- Student marked as "Withdrawn"
- Removed from active class lists
- Historical records preserved
- Parent account remains active (can still access historical data)

### Step 4: Parent Account

**Parent Portal Access:**
- Parent can still log in
- Can view historical grades and report cards
- Can download past documents
- Cannot see current term activity (as student is withdrawn)

### Step 5: Final Settlement

**Before Issuing Documents:**
1. ✅ **Verify all fees paid**
2. ✅ **Verify all school property returned**
3. ✅ **Clear any outstanding obligations**

**Issue Transfer Documents:**
1. ✅ **Parent collects documents from school office**
2. ✅ **Parent signs acknowledgment of receipt**
3. ✅ **Admin keeps copy in student file**

### Step 6: Follow-Up

**Optional but Good Practice:**
1. ✅ **Wish student well** - send goodbye message via parent portal
2. ✅ **Request feedback** - why they're leaving (helps school improve)
3. ✅ **Update statistics** - track student attrition rates

## Parent-Teacher Communication Flow {#parent-teacher-communication}

This workflow shows how effective communication happens between parents and teachers.

### Scenario 1: Parent Initiates Contact

**Parent Has a Question or Concern:**

**Step 1: Parent Sends Message**
1. ✅ **Parent logs into 4SCH**
2. ✅ **Goes to Messages → New Message**
3. ✅ **Selects teacher** (class teacher or subject teacher)
4. ✅ **Writes clear, specific message**
5. ✅ **Clicks Send**

**Good Parent Message Example:**
> "Dear Mrs. Adeleke,
>
> I've noticed my daughter Chioma's Math scores have dropped from 75% to 55% this term. She seems to be struggling with algebra specifically.
>
> Could we discuss strategies to help her improve? Are there any extra lessons or tutoring available?
>
> Thank you."

**Step 2: Teacher Receives Notification**
- Email notification: "New message from parent"
- In-app notification on dashboard
- SMS (if enabled)

**Step 3: Teacher Responds**
1. ✅ **Teacher logs in to 4SCH**
2. ✅ **Goes to Messages → Inbox**
3. ✅ **Reads parent message**
4. ✅ **Replies within 24 hours** (best practice)

**Good Teacher Response Example:**
> "Dear Mrs. Okafor,
>
> Thank you for reaching out. I've also noticed Chioma's struggle with algebra. She works hard but needs more practice.
>
> I recommend:
> 1. Extra practice problems - I'll send some worksheets via 4SCH
> 2. After-school tutoring on Tuesdays 3-4pm (free)
> 3. Online resource: [website link]
>
> Let's monitor her progress over the next two weeks. Please feel free to message me with updates.
>
> Best regards,
> Mrs. Adeleke"

**Step 4: Parent Sees Response**
- Receives notification
- Can reply with follow-up questions
- Thread continues until resolved

### Scenario 2: Teacher Initiates Contact

**Teacher Has Concern About Student:**

**Step 1: Teacher Identifies Issue**
Examples:
- Student's performance declining
- Behavioral problem
- Excessive absences
- Outstanding assignment

**Step 2: Teacher Documents**
1. ✅ **Collect evidence:**
   - Grade records
   - Attendance records
   - Specific incidents with dates

**Step 3: Teacher Messages Parent**
1. ✅ **Go to class list**
2. ✅ **Click on student**
3. ✅ **Click "Message Parent"**
4. ✅ **Write professional, constructive message**

**Good Teacher Message Example:**
> "Dear Mr. and Mrs. Ibrahim,
>
> I hope this message finds you well. I wanted to discuss David's performance in English Language.
>
> Observations:
> - David has submitted only 2 out of 5 assignments this term
> - His last test score was 42% (below his usual 60-70% range)
> - He seems distracted during lessons
>
> I'd like to understand if there's anything affecting him at home or school so we can help him get back on track.
>
> Could we arrange a brief meeting or phone call this week?
>
> Best regards,
> Mr. Eze"

**Step 4: Parent Responds**
- Receives notification
- Appreciates teacher's concern
- Provides context or requests meeting

**Step 5: Resolution**
- **Option 1:** Resolved via messaging
- **Option 2:** Schedule face-to-face meeting
- **Option 3:** Involve school counselor/admin

### Scenario 3: Regular Updates

**Teacher Sends Positive News:**

**Celebration Messages:**
Teachers should also message parents with good news, not just problems!

**Example:**
> "Dear Mrs. Adeyemi,
>
> I wanted to share some great news! Tunde scored 95% on our recent Science test - the highest in the class!
>
> His improvement this term has been remarkable. His curiosity and hard work are really paying off.
>
> Keep encouraging him - he's doing wonderfully!
>
> Best regards,
> Mr. Johnson"

**Why This Matters:**
- Builds positive parent-teacher relationship
- Encourages student
- Motivates continued effort
- Parents appreciate being kept informed

### Communication Best Practices

**For Teachers:**
1. ✅ **Respond within 24 hours** during weekdays
2. ✅ **Be professional and courteous**
3. ✅ **Be specific** - use data and examples
4. ✅ **Be solution-oriented**
5. ✅ **Keep admin in loop** for serious issues
6. ✅ **Document all communication**

**For Parents:**
1. ✅ **Be respectful** in messages
2. ✅ **Be specific** about concerns
3. ✅ **Give teachers time** to respond (24-48 hours)
4. ✅ **Follow up** if no response after 2 days
5. ✅ **Escalate appropriately** - teacher → class teacher → head of department → principal

**For Admins:**
1. ✅ **Monitor message response times**
2. ✅ **Step in for unresolved conflicts**
3. ✅ **Provide communication training** for new teachers
4. ✅ **Set clear communication policies**

### Escalation Process

**If issue is not resolved at teacher level:**

**Level 1: Class Teacher**
- Parent messages class teacher
- Class teacher coordinates with subject teachers

**Level 2: Head of Department**
- If unresolved, escalate to HOD
- HOD reviews situation and mediates

**Level 3: Principal/Admin**
- For serious issues or unresolved conflicts
- Principal makes final decision

**Level 4: School Board** (rare)
- Only for exceptional circumstances
- Formal complaints

## Tips for Successful Workflows

### For Administrators

1. **Plan Ahead**
   - Use the timelines above as checklists
   - Set reminders for key tasks
   - Don't wait until the last minute

2. **Communicate Clearly**
   - Keep all stakeholders informed
   - Set clear expectations and deadlines
   - Follow up on pending tasks

3. **Monitor Progress**
   - Use 4SCH reports to track completion
   - Address bottlenecks quickly
   - Recognize and appreciate timely completion

4. **Be Flexible**
   - Have backup plans for tech issues
   - Be prepared for unexpected challenges
   - Adapt workflows to your school's context

### For Teachers

1. **Stay Organized**
   - Mark attendance immediately after class
   - Enter grades promptly
   - Don't let tasks pile up

2. **Communicate Proactively**
   - Don't wait for parents to ask
   - Share both concerns and celebrations
   - Keep admin informed of issues

3. **Use the System**
   - Log into 4SCH daily
   - Check messages regularly
   - Use available features (gradebook, messaging)

### For Parents

1. **Stay Engaged**
   - Check 4SCH regularly
   - Respond to messages promptly
   - Pay fees on time

2. **Communicate Respectfully**
   - Be professional in messages
   - Give teachers time to respond
   - Work collaboratively

3. **Support Your Child**
   - Review grades together
   - Discuss attendance
   - Celebrate successes and address challenges
