# Keyboard Shortcuts

Speed up your workflow with these keyboard shortcuts for the web-based school management system.

:::info Browser Compatibility
Most shortcuts work in Chrome, Firefox, Edge, and Safari. Some browser-specific shortcuts may vary.
:::

---

## 🌐 Global Navigation

These shortcuts work from any page within the system.

| Shortcut | Action | Notes |
|----------|--------|-------|
| `Alt + D` or `Cmd + D` | Go to Dashboard | Return to main dashboard |
| `Ctrl + K` or `Cmd + K` | Open search | Quick search (if available) |
| `Esc` | Close modal/popup | Closes any open dialog boxes |
| `Ctrl + /` or `Cmd + /` | Show keyboard shortcuts | Display this help menu (if implemented) |

---

## 📄 Page Navigation

| Shortcut | Action | Notes |
|----------|--------|-------|
| `Tab` | Next field | Move to next form field or button |
| `Shift + Tab` | Previous field | Move to previous form field |

| `Ctrl + Home` or `Cmd + ↑` | Top of page | Scroll to top |
| `Ctrl + End` or `Cmd + ↓` | Bottom of page | Scroll to bottom |
| `Space` | Scroll down | Scroll one page down |
| `Shift + Space` | Scroll up | Scroll one page up |

## 💡 Productivity Tips

### Browser-Level Shortcuts

**Tab Management:**
- `Ctrl + T` or `Cmd + T` - New tab
- `Ctrl + W` or `Cmd + W` - Close current tab
- `Ctrl + Shift + T` or `Cmd + Shift + T` - Reopen closed tab
- `Ctrl + Tab` or `Cmd + Option + →` - Next tab
- `Ctrl + Shift + Tab` or `Cmd + Option + ←` - Previous tab

**Page Actions:**
- `F5` or `Ctrl + R` or `Cmd + R` - Refresh page
- `Ctrl + Shift + R` or `Cmd + Shift + R` - Hard refresh (clear cache)
- `Ctrl + +` or `Cmd + +` - Zoom in
- `Ctrl + -` or `Cmd + -` - Zoom out
- `Ctrl + 0` or `Cmd + 0` - Reset zoom to 100%

**Navigation:**
- `Alt + ←` or `Cmd + [` - Back
- `Alt + →` or `Cmd + ]` - Forward
- `Ctrl + L` or `Cmd + L` - Focus address bar

---

### Text Editing Tips

**Word Navigation:**
- `Ctrl + ←` or `Option + ←` - Previous word
- `Ctrl + →` or `Option + →` - Next word
- `Ctrl + Backspace` or `Option + Backspace` - Delete previous word
- `Ctrl + Delete` or `Option + Delete` - Delete next word

**Line Navigation:**
- `Home` or `Cmd + ←` - Start of line
- `End` or `Cmd + →` - End of line
- `Ctrl + Home` or `Cmd + ↑` - Start of document
- `Ctrl + End` or `Cmd + ↓` - End of document

---

### System-Specific Tips

**Quick Actions:**
1. **Bookmark frequently used pages** - Use `Ctrl + D` or `Cmd + D` to bookmark important pages (Student List, Attendance, etc.)
2. **Use browser's back button** - `Alt + ←` or `Cmd + [` instead of clicking back
3. **Open links in new tab** - `Ctrl + Click` or `Cmd + Click` on any link

**Form Filling:**
1. **Tab through fields** - Use `Tab` instead of mouse clicking
2. **Auto-fill** - Enable browser auto-fill for repetitive data entry
3. **Copy-paste** - Use keyboard shortcuts instead of right-click menu

**Multiple Records:**
1. **Duplicate tab** - `Ctrl + Click` or `Cmd + Click` on menu items to open in new tab
2. **Compare data** - Open same record in two tabs side-by-side
3. **Bulk operations** - Select multiple checkboxes with `Shift + Click`

For tablets and mobile phones:

**Touch Gestures:**

## ⚙️ Accessibility Shortcuts

For users relying on keyboard navigation:

| Shortcut | Action | Notes |
|----------|--------|-------|
| `Tab` | Next focusable element | Navigate through interactive elements |
| `Shift + Tab` | Previous focusable element | Navigate backwards |
| `Enter` or `Space` | Activate | Click buttons or checkboxes |
| `Arrow keys` | Navigate lists | Move through dropdowns and lists |
| `Esc` | Cancel | Close dialogs or cancel actions |

**Screen Reader Users:**
- Use your screen reader's navigation shortcuts
- Form labels are provided for all input fields
- Error messages are announced
- Tables include proper headers

## 🚀 Power User Workflows

### Morning Admin Routine (5 minutes)
```
1. Alt + D → Go to dashboard
2. Check today's attendance (bookmark this page)
3. Ctrl + T → New tab
4. Check pending approvals
5. Ctrl + T → New tab  
6. Review fee collection status
7. Close tabs when done
```

### Bulk Student Entry
```
1. Open student import page (bookmark it)
2. Download template (Ctrl + J to view downloads)
3. Fill Excel offline
4. Upload file
5. Review validation errors
6. Tab through error rows
7. Enter to submit
```

### Quick Attendance Marking
```
1. Navigate to attendance page
2. Tab to first student
3. Press P for Present, A for Absent (if hotkeys enabled)
4. Tab to next student
5. Repeat
6. Ctrl + Enter to submit
```
