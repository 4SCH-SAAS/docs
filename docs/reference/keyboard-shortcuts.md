# Keyboard Shortcuts & Power User Guide

Speed up your workflow with these keyboard shortcuts for the web-based school management system. Whether you're an Administrator, Teacher, Student, or Power User, this guide covers all the shortcuts, advanced workflows, and productivity tips you need.

:::info Browser Compatibility
Most shortcuts work in Chrome, Firefox, Edge, and Safari. Some browser-specific shortcuts may vary. Mobile gestures work on all touch-enabled devices.
:::

:::note Nigerian Educational Context
This guide includes examples and tips relevant to Nigerian schools, including references to commonly used modules like Attendance (for classroom management), Grades (for continuous assessment), and Fees (for school financing).
:::

## 🚄 Advanced Power User Tips

### 🎯 Bulk Operations & Multi-Select

Efficiently manage multiple records at once:

| Operation | Shortcuts | Example |
|-----------|-----------|---------|
| **Select All** | `Ctrl + A` | Select all students in a class |
| **Select Multiple** | `Ctrl + Click` | Select specific students while skipping others |
| **Select Range** | `Shift + Click` | Select consecutive rows from first to last |
| **Select Inverse** | `Ctrl + Shift + A` | Select all except currently selected |
| **Deselect All** | `Esc` | Clear all selections |
| **Deselect One** | `Ctrl + Click` | Click again to deselect single item |
| **Toggle Selection** | `Space` | Toggle current item selection |

**Multi-Select Workflows:**

**Bulk Mark Attendance (Nigerian Context):**
```
1. Alt + A → Open attendance page
2. Ctrl + A → Select all students in class
3. P → Mark all as present
4. Shift + Click → Select absentees only
5. A → Mark as absent
6. Ctrl + Enter → Save all
```

**Bulk Update Student Records:**
```
1. Navigate to Student Management
2. Ctrl + F → Find students (e.g., by class or surname)
3. Shift + Click → Select students from Okafor to Okeke
4. Ctrl + E → Bulk edit field (e.g., update house or stream)
5. Enter → Confirm changes
```

**Bulk Process Fee Payments:**
```
1. Alt + F → Open fees module
2. Ctrl + F → Filter by "Pending" status
3. Ctrl + A → Select all pending payments
4. Ctrl + Alt + M → Send reminder message to parents
5. Wait for payments, then Ctrl + R to refresh list
```

**Bulk Grade Entry (End of Term):**
```
1. Alt + G → Open gradebook
2. Ctrl + Alt + G → Enter bulk grading mode
3. Tab through students entering marks
4. Ctrl + D → Duplicate marks across parallel classes
5. Ctrl + Enter → Save all grades
6. Ctrl + E → Export grades for report cards
```

For users accessing the system on smartphones and tablets:

### Universal Touch Gestures

| Gesture | Action | Notes |
|---------|--------|-------|
| **Swipe Left** | Previous screen | Navigate backwards in workflow |
| **Swipe Right** | Next screen | Navigate forwards in workflow |
| **Swipe Down** | Refresh | Pull-to-refresh (reload data) |
| **Swipe Up** | Collapse menu | Hide navigation menu |
| **Two-Finger Pinch Out** | Zoom in | Zoom in on tables/text |
| **Two-Finger Pinch In** | Zoom out | Zoom out to see full table |
| **Two-Finger Rotate** | Rotate screen | Rotate screen orientation |
| **Long Press** | Context menu | Show right-click menu (copy, delete, etc.) |
| **Double Tap** | Zoom/Full screen | Toggle full screen on data tables |
| **Triple Tap** | Select all text | Select entire text block |

### Application-Specific Mobile Gestures

| Gesture | Location | Action | Notes |
|---------|----------|--------|-------|
| **Swipe Left** | Attendance list | Mark student as absent | Quick marking gesture |
| **Swipe Right** | Attendance list | Mark student as present | Quick marking gesture |
| **Swipe Left** | Grade entry | Increment grade by 1 | Rapid grade entry |
| **Swipe Right** | Grade entry | Decrement grade by 1 | Rapid grade entry |
| **Tap & Hold** | Message list | Select message | Enable multi-select |
| **Swipe Left** | Message | Delete/Archive message | Quick cleanup |
| **Tap ⋮ Menu** | Any record | Open actions menu | Edit, delete, print options |
| **Long Press Category** | Report list | Filter by category | Quick filter selection |

### Mobile Form Entry Tips

**Efficient Data Entry on Mobile:**

1. **Use Mobile Keyboards Wisely**
   - Tap number field to show numeric keyboard
   - Tap email field to show email keyboard with @ and .com
   - Tap date field to show date picker instead of typing

2. **Autocomplete & Suggestions**
   - Start typing a student name and tap suggestion
   - Don't type full names - autocomplete will find them
   - Use class filter before searching for students

3. **Voice Input (if enabled)**
   - Tap microphone icon in text fields
   - Use for longer text like notes or messages
   - Helpful for teachers adding feedback on assignments

4. **Copy/Paste on Mobile**
   - Long press field and select "Paste"
   - Useful for batch updates with same value
   - Example: Paste same house name for multiple students

5. **Navigate Faster on Mobile**
   - Tap "Jump to Top" button instead of scrolling
   - Use tabs to switch between sections
   - Swipe to move between forms (if supported)

### Mobile Device Recommendations

**For Nigerian Schools:**
- **Android Tablets** (10-inch) - Best for marking attendance in class
- **iPad** (10.2-inch) - Smooth gradebook experience
- **Smartphones** - Good for checking grades and messages, poor for data entry
- **Chromebooks** - Best for desktop-like keyboard experience without laptop cost

**Mobile Optimization Tips:**
- Use landscape orientation for tables and gradebooks
- Zoom to 125% for better visibility on small screens
- Turn off notifications while marking attendance to avoid distractions
- Charge device daily if using for attendance marking (critical in Nigerian schools)

## 🌍 Localization Notes for Nigerian Context

**Keyboard Layout Considerations:**

Many Nigerian schools use Windows computers with English-US keyboard layouts. Here are important notes:

- **QWERTY Layout (Standard)** - All shortcuts in this guide assume QWERTY layout
- **Shift + Key** combos may be affected by keyboard layout - test Alt combinations
- **Special Characters** - Some schools may have French AZERTY or other layouts
- **Check Your Layout** - Windows: Settings > Time & Language > Language > Add Input Method

**Common Adaptations for Nigerian Schools:**

| Situation | Adaptation |
|-----------|-----------|
| Using non-QWERTY keyboard | Test Alt+A before training staff |
| Limited IT support | Prioritize learning the 10 essential shortcuts |
| Mobile-first staff | Focus on mobile gesture section |
| Slow internet | Use Ctrl+C to copy attendance offline, sync when online |
| Shared devices | Use Ctrl+Shift+Del to clear cache before logout |
| Computer labs | Post cheat sheet in prominent location |

**Nigerian Educational Context Examples:**

- **Continuous Assessment (CA)** - Use `Alt + G` for quick entry of CA marks throughout term
- **House System** - Use bulk assign function to update all students in a house
- **WAEC/JAMB Prep** - Use reports module to track performance toward external exams
- **Fee Collection** - Use `Alt + F` → `Ctrl + E` to export for school accountant
- **Staff Meetings** - Print cheat sheet and distribute in staff meetings quarterly

## 📚 Learning Shortcuts - Progressive Mastery

Master keyboard shortcuts progressively. Don't try to learn everything at once!

### Level 1: Essential Basics (Start Here)
**Time to Master: 1 week**

Focus only on these 5 shortcuts:
1. `Tab` / `Shift + Tab` - Navigate between fields
2. `Enter` - Submit and confirm
3. `Esc` - Close dialogs
4. `Ctrl + S` / `Cmd + S` - Save
5. `Ctrl + F` / `Cmd + F` - Find on page

**Benefit:** Can complete most tasks, just slower than mouse

### Level 2: Role-Specific Mastery (Week 2-3)
**Time to Master: 2 weeks**

Learn your role's main shortcuts:
- **Admins:** `Alt + A`, `Alt + 1`, `Ctrl + Alt + I`, `Ctrl + Alt + R`
- **Teachers:** `Alt + T`, `Alt + G`, `Alt + A`, `Shift + Alt + R`
- **Students:** `Alt + S`, `Alt + R`, `Alt + A`, `Alt + F`

**Benefit:** 50% faster than mouse for routine tasks

### Level 3: Module Power User (Week 4-6)
**Time to Master: 3-4 weeks**

Master all shortcuts in your primary module:
- Attendance specialists: All attendance shortcuts
- Grade specialists: All gradebook shortcuts
- Messaging specialists: All messaging shortcuts

**Benefit:** 80% faster, smooth workflow, fewer mouse clicks

### Level 4: Advanced Power User (Week 7+)
**Time to Master: Ongoing**

Learn workflow accelerators, multi-select, and bulk operations:
- Combine multiple shortcuts in sequences
- Use multi-select for bulk operations
- Create custom workflows

**Benefit:** Complete complex tasks in record time

## ✅ Troubleshooting Shortcuts

### Shortcut Not Working?

**Check these first:**
1. **Verify keyboard layout:** Windows Settings > Time & Language > Language
2. **Browser might be blocking:** Try using incognito/private mode
3. **Check system shortcuts:** Some OS shortcuts override app shortcuts
4. **Clear browser cache:** `Ctrl + Shift + Del` then refresh
5. **Disable extensions:** Temporarily disable extensions that might conflict
6. **Update browser:** Ensure you're on latest version

**Still not working?**
- Try the Mac equivalent (e.g., `Cmd` instead of `Ctrl`)
- Check if feature requires specific permissions
- Contact support: help@schoolmanagementsystem.ng

### Specific Module Shortcuts Not Available?

**Possible reasons:**
- Feature may not be enabled for your role
- Module requires additional configuration
- Older version of system - update to latest
- Feature is in development - check roadmap

**Solution:**
- Contact your school administrator or support team
- Request feature to be enabled if available
- Provide feedback if you need custom shortcuts
