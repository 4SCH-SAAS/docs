## 🔄 COMMON WORKFLOWS

### Workflow 1: Create Assignment
1. **Access Assignment Module** → Click "Create New Assignment"
2. **Enter Details:**
   - Title: e.g., "Mathematics Chapter 5 Exercises"
   - Description: Clear instructions in English/Yoruba/Igbo
   - Due Date: Set deadline (e.g., 15 Jan 2024)
   - Point Value: ₦0 (or marks if applicable - max 100)
3. **Attach Resources** → Upload PDF/Word files or embed video links
4. **Set Submission Type** → Select: File Upload, Text Entry, or Both
5. **Publish** → Click "Publish to Class" to make visible to students
6. **Notification** → Students (e.g., Chukwudi, Amara, Zainab) receive alert

### Workflow 2: Enter Exam Marks
1. **Navigate** → Gradebook → Select Exam/Test
2. **Enter Scores:**
   - Student Name | Mark (out of 100)
   - Chukwudi Okonkwo | 85
   - Amara Uchenna | 92
   - Zainab Hassan | 78
3. **Add Comments** (Optional) → Positive feedback or areas for improvement
4. **Save & Publish** → Marks visible to students and parents
5. **Generate Report** → Download class performance summary (Excel/PDF)
6. **Check Anomalies** → Flag unusually high/low scores for review

### Workflow 3: Send Messages to Students
1. **Open Messaging** → Dashboard → Messages or individual student profile
2. **Select Recipients:**
   - Individual Student: Click student name
   - Entire Class: "Select All" or "Broadcast"
   - Specific Group: Use class sections/groups
3. **Compose Message:**
   - Subject: Clear title (e.g., "Assignment Deadline Reminder")
   - Body: Friendly, professional tone with clear action items
   - Example: "Dear Chukwudi, your Mathematics assignment is due Friday. Please submit by 4 PM."
4. **Add Attachments** (Optional) → Guidelines, rubrics, solutions
5. **Schedule** → Send now or schedule for later (e.g., Monday 7 AM)
6. **Confirm** → Review message before sending

## 🆘 TROUBLESHOOTING TIPS

### Issue: Student Can't Submit Assignment
**Symptoms:** Student (e.g., Chukwudi) reports "Submit button not working"

**Quick Fixes:**
1. **Check Deadline** → Is assignment still open? (Not passed due date)
   - Solution: Extend due date in Assignment Settings if needed
2. **Browser Cache** → Have student clear cache and refresh
   - Shortcut: `Ctrl + Shift + Delete` → Clear browsing data
3. **File Type Issue** → Verify student uploaded allowed format (PDF, Word, Image)
   - Solution: Request file conversion or provide alternative submission method
4. **Connectivity** → Check if student has stable internet
   - Workaround: Allow offline submission via email with timestamp
5. **Account Issue** → Verify student is enrolled in class
   - Action: Check class roster; re-enroll if necessary

**Escalation:** Contact IT Support with student name, assignment ID, and timestamp of error

---

### Issue: Marks Not Saving
**Symptoms:** Entered marks disappear after saving/refreshing

**Quick Fixes:**
1. **Auto-Save Enabled?** → Check Settings → Auto-save should be ON
2. **Internet Connection** → Ensure stable connection while entering marks
3. **Session Timeout** → You may have been logged out
   - Solution: Log in again and re-enter marks with fresh session
4. **Browser Compatibility** → Use Chrome, Firefox, or Edge (avoid Safari on older versions)
5. **Gradebook Locked?** → Check if marks are locked by admin for that term
   - Solution: Request unlock from Department Head or IT

**Prevention Tips:**
- Enter marks in batches of 10-15 students maximum per session
- Take screenshots of marks before saving (Ctrl + Print Screen)
- Export gradebook weekly as backup (Ctrl + Shift + E)
- Use CSV upload for large batches instead of manual entry

**Data Recovery:** Contact IT Support with details; backups are typically 24-48 hours old

---

### Issue: Can't Access Attendance Module
**Symptoms:** Attendance button grayed out or page won't load

**Quick Fixes:**
1. **Permissions Check** → Verify you're an assigned class teacher
2. **Time Window** → Some schools lock attendance after class time ends
3. **Class Not Activated** → Ensure class is active in current term
4. **Browser Issue** → Clear cache (Ctrl + Shift + Delete) and refresh
5. **Mobile View Problem** → Switch to desktop view for full functionality

## 💡 PRO TIPS FOR TEACHERS

1. **Grade Immediately** → Enter marks within 24 hours while fresh; students appreciate quick feedback
2. **Batch Operations** → Use "Select All" + bulk actions to save time on repetitive tasks
3. **Time Management** → Block 30 minutes daily for grading; don't accumulate backlog
4. **Backup Habit** → Export gradebook weekly (Ctrl + Shift + E) to local computer
5. **Parent Engagement** → Message parents monthly with positive update, not just problems
6. **Attendance Consistency** → Mark attendance at same time daily (e.g., 8:15 AM)
7. **Deadline Clarity** → Always specify time (e.g., "4:00 PM Friday" not just "Friday")
8. **Fair Grading** → Use consistent rubric; write specific feedback, not just marks
9. **Mobile Backup** → Screenshot important marks before they're due for submission
10. **Tech Support** → Keep IT contact info handy; report issues immediately, not later

## 🖨️ PRINT INSTRUCTIONS

**Optimal Printing Setup:**
- **Format:** Landscape orientation recommended (fits better on 1-2 pages)
- **Paper Size:** A4 (standard)
- **Margins:** 0.5 inches (reduce margins for tighter fit)
- **Color:** Print in color for better readability of tables
- **Font Size:** Default (100%) or reduce to 85% if needed to fit
- **Background:** Disable background graphics to save ink
- **Pages:** Print pages 1-2 (or 1-3 depending on margins)

**CSS Print Notes:**
