## 📐 Technical Specifications

### Dimensions & Format
- **Size:** 1280 x 720 pixels (16:9 ratio)
- **Format:** JPG or PNG
- **File Size:** < 2 MB per thumbnail
- **Resolution:** 72 DPI (screen optimized)
- **Color Mode:** RGB

### Safe Zones
- **Title Safe Zone:** 1120 x 630 pixels (centered)
- **Action Safe Zone:** 1180 x 664 pixels
- **Minimum text height:** 72 pixels for readability on mobile

## 🎨 Brand Guidelines

### Color Palette

**Primary Colors:**
- **4SCH Green:** #2e8555 (Main brand color)
- **Dark Green:** #1d5438 (Accents, shadows)
- **Light Green:** #4caf50 (Highlights, icons)

**Secondary Colors:**
- **Deep Navy:** #1a1a2e (Background base)
- **Charcoal:** #16213e (Text background overlay)
- **Pure White:** #ffffff (Primary text)
- **Light Gray:** #e0e0e0 (Secondary text)

**Accent Colors (Role-Based):**
- Admin: #ff6b6b (Coral Red)
- Teacher: #4ecdc4 (Teal)
- Parent: #ffd93d (Golden Yellow)
- Student: #6bcf7f (Light Green)
- Accountant: #95e1d3 (Mint)
- Driver: #f38181 (Soft Red)
- Support Staff: #aa96da (Lavender)

### Typography

**Primary Font:** Poppins (Bold, SemiBold, Medium)
- **Title:** Poppins Bold, 72-90px
- **Subtitle:** Poppins SemiBold, 42-54px
- **Label:** Poppins Medium, 32-38px

**Fallback Font:** Roboto or Open Sans

**Text Effects:**
- Drop shadow: 4px offset, 60% opacity, black
- Stroke (optional): 3px white for dark backgrounds

### Badges Design Specs
**Duration Badges:**
- Size: 120 x 50 pixels
- Background: 4SCH green (#2e8555)
- Text: White, Poppins Bold, 24px
- Border radius: 8px
- Position: Bottom right corner, 20px margin

**Chapter Badges:**
- Size: 180 x 50 pixels
- Background: White with 10% opacity
- Text: White, Poppins SemiBold, 22px
- Border: 2px white
- Border radius: 8px
- Position: Bottom right, above duration

**Series Badges:**
- Size: Variable width x 45 pixels
- Background: Charcoal (#16213e)
- Text: Light gray (#e0e0e0), Poppins Medium, 20px
- Border radius: 6px
- Position: Bottom center or left

## ✅ Quality Checklist

Before finalizing each thumbnail:

- [ ] Dimensions exactly 1280 x 720 pixels
- [ ] File size under 2 MB
- [ ] Text readable on mobile (min 72px height)
- [ ] 4SCH logo included (top left, consistent size)
- [ ] Brand colors used correctly
- [ ] No spelling errors in title/subtitle
- [ ] Duration badge accurate
- [ ] High contrast for readability (4.5:1 minimum)
- [ ] Consistent style across series
- [ ] Appealing visual hierarchy
- [ ] Professional and polished appearance
