- Fade in with conversation icon

- Use warm, inviting background music
- Gentle fade-in effect
- Voice should feel approachable and professional

### Why Parent Messaging Matters (0:30 - 1:15)

**Visual Cues:**
- Show benefits with animated icons:
  - Chat bubble (direct conversation)
  - Lock icon (secure/private)
  - Clock icon (asynchronous communication)
  - Document icon (record keeping)
- Display sample parent-teacher conversation

**Voiceover Script:**
"Parent Messaging goes beyond announcements. It creates a private channel between you and each parent. These conversations stay in one place, creating a record of your communication. This is invaluable when discussing student behavior, academic progress, or upcoming parent-teacher conferences.

The messaging system is asynchronous, meaning parents can respond when they're free—whether that's during lunch or after work. Messages are secure and professional, keeping your communication appropriate and documented for accountability."

**Production Notes:**
- Animate each benefit icon as it's mentioned
- Show real conversation example (with student names changed)
- Keep message previews readable
- Use subtle transitions between benefits

### Step 1: Accessing Parent Messaging (1:15 - 1:50)

**Visual Cues:**
- Screen recording: Navigate to Communications
- Click "Messages" or "Parent Messaging"
- Show inbox with conversation list
- Highlight unread message indicators

**Voiceover Script:**
"Let's start by accessing the Parent Messaging feature. From your dashboard, go to the main menu and select 'Communications.' You'll see several options—choose 'Messages' or 'Parent Messaging.' This opens your message inbox, where you'll see all ongoing conversations with parents.

Each conversation shows the parent's name, last message preview, and timestamp. Unread messages are highlighted so you know what needs your attention."

**Production Notes:**
- Record cursor movements smoothly
- Zoom in on the messages section
- Highlight the unread indicator with a subtle animation
- Show 3-4 example conversations on screen

### Step 2: Starting a New Conversation (1:50 - 2:45)

**Visual Cues:**
- Screen recording: Click "New Message" or "+" button
- Show recipient selection screen
- Search/filter for parent names
- Display suggested recipients (frequently contacted)

**Voiceover Script:**
"To start a new conversation, click the 'New Message' or plus button, usually located at the top of your inbox. A dialog will open asking you to select a recipient. You can search by the parent's name, student name, or email address.

The system often suggests recent contacts or frequently messaged parents, making it quick to select who you want to reach. You can message one parent at a time to keep conversations personal and focused.

Once you've selected the parent, you'll move to the message composition screen."

**Production Notes:**
- Show search functionality in action
- Demonstrate filtering/searching
- Display suggested recipients clearly
- Use smooth transitions between steps
- Keep pace moderate for viewers to follow along

### Step 3: Composing Your Message (2:45 - 3:45)

**Visual Cues:**
- Show message composition area
- Display text formatting options (bold, italic, lists)
- Show attachment option
- Display character counter
- Show template suggestions (if available)

**Voiceover Script:**
"Now you're in the message composition area. Type your message directly into the text field. Keep your tone professional yet warm—you're building a relationship with this parent.

The messaging system includes basic formatting options. You can bold important points, use bullet lists for clarity, and italicize key terms. These subtle formatting choices make your message easier to read.

If you need to share documents—like a recent quiz, progress report, or assignment—use the attachment button. You can attach PDFs, images, or other relevant files. This keeps all communication in one organized space.

Notice the character counter? It helps you keep messages concise. While there's usually a generous limit, shorter, focused messages tend to get better responses from busy parents.

If you send messages regularly, you might find template suggestions—pre-written responses you can customize. This saves time while maintaining personal touches."

**Production Notes:**
- Record typing at a natural pace
- Demonstrate formatting options with examples
- Show attachment dialog briefly
- Highlight character counter
- Pause slightly when introducing templates
- Use example messages that are classroom-appropriate

### Step 4: Sending and Managing Conversations (3:45 - 4:35)

**Visual Cues:**
- Show "Send" button
- Display confirmation/sent status
- Show parent's response arriving
- Demonstrate conversation threading
- Show mark as resolved/archive options

**Voiceover Script:**
"When you're ready, click 'Send.' Your message is delivered immediately, and you'll see it appear in the conversation thread. The parent will receive a notification and can reply at their convenience.

As the conversation develops, all messages appear in a thread format, making it easy to follow the entire discussion. This context is crucial—you and the parent can see the full history of what's been discussed.

If a conversation has been resolved or concluded—like after a parent-teacher conference—you can mark it as resolved or archive it. This keeps your active inbox focused on ongoing matters while preserving the record of past conversations."

**Production Notes:**
- Show send button clearly
- Animate the message appearing in the thread
- Display notification that parent receives
- Show example response arriving
- Demonstrate archive function
- Use smooth transitions between actions

---

### Best Practices (4:35 - 4:50)

**Visual Cues:**
- Slide-based tips with icons
- Checkmark for each practice
- Red X for practices to avoid

**Voiceover Script:**
"Here are best practices for effective parent messaging:

One: Respond promptly. Aim to reply within 24 business hours. Parents appreciate knowing you're accessible.

Two: Stay professional. Keep your tone respectful and focused on the student's growth and success.

Three: Be specific. Instead of 'Your student is struggling,' say 'Sarah is struggling with long division. We're working on it in class, and practicing five problems daily at home would help.'

Four: Avoid scheduling sensitive conversations via message. If you need to discuss serious behavioral or academic concerns, suggest a phone call or in-person meeting.

Five: Don't message outside school hours unless truly urgent. Respect parents' personal time."

**Production Notes:**
- One tip per slide
- Use positive/negative visual indicators
- Keep text minimal
- Maintain consistent background
- Use professional color scheme
