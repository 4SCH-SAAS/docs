## [01:00-02:15] Creating Your First Exam (75 sec)

**[VISUAL]** Screen recording: Exam Setup wizard

**[VOICEOVER]:**  
"Let's create your first exam from start to finish. From the admin dashboard, navigate to Academic → Exams → Create New Exam."

**[SCREEN RECORDING - Step 1: Basic Information]**
- Click "Create Exam"
- Enter exam name (e.g., "First Term Examinations 2024")
- Select exam type: School Exam, Mock Exam, Continuous Assessment, Remedial
- Choose start and end dates
- Select affected classes/forms

**[VOICEOVER]:**  
"Step one: Enter basic information. Give your exam a clear name, select the exam type - is this a formal school exam, a mock test, or continuous assessment? Then set the date range and choose which classes will participate."

**[SCREEN RECORDING - Step 2: Configure Subjects & Durations]**
- Click "Add Subjects"
- Select from school curriculum
- Set exam duration (e.g., 2.5 hours for Mathematics)
- Configure whether subjects are compulsory or elective
- Set marks allocation (total out of 100)

**[VOICEOVER]:**  
"Step two: Configure your subjects. Select all subjects that will have exams. For each subject, set the duration - Mathematics might be two and a half hours while English is two hours. Specify total marks. You can mark subjects as compulsory or elective based on student choices."

**[SCREEN RECORDING - Step 3: Schedule Exam Timetable]**
- Click "Schedule Exam Timetable"
- Drag subjects into date/time slots
- System checks for room availability
- Assign invigilators automatically or manually
- Set buffer time between exams

**[VOICEOVER]:**  
"Step three: Create your exam timetable. Schedule each subject across different days. The system prevents double-booking of examination halls. You can assign invigilators automatically or manually manage who supervises which exam. Set buffer time - perhaps 30 minutes between exams - so students can rest."

## [02:15-03:45] Setting Up Marking Schemes (90 sec)

**[VISUAL]** Marking rubric interface being built

**[VOICEOVER]:**  
"With subjects scheduled, now configure how each exam will be marked. This is crucial for ensuring consistency and fairness across all markers."

**[SCREEN RECORDING - Marking Scheme Setup]**
- Click "Marking Schemes"
- Select first subject (e.g., English Language)
- View question paper structure
- Add sections with allocated marks

**[VOICEOVER]:**  
"Click 'Marking Schemes' and select your first subject. You'll see the question paper structure. Allocate marks to each section. For example, in English Language exam, section A - Comprehension might be 40 marks, section B - Essay might be 60 marks."

**[SCREEN RECORDING - Configure Assessment Criteria]**
- Add assessment rubric
- Define performance levels: Excellent, Good, Average, Poor
- Attach descriptors to each level
- Show mark range for each level

**[VOICEOVER]:**  
"Now set up your assessment criteria. Define performance levels - maybe 'Excellent' is 80-100%, 'Good' is 70-79%, 'Average' is 60-69%, and 'Poor' is below 60%. You can attach detailed descriptors so markers understand exactly what constitutes each grade."

**[SCREEN RECORDING - Assigning Markers]**
- Click "Assign Markers"
- Select subject
- Add teacher marking team (primary, secondary, senior marker)
- Set marking deadline (e.g., 7 days from exam date)
- Enable or disable moderation
- Configure cross-checking requirements

**[VOICEOVER]:**  
"Assign your marking team. Each exam can have a primary marker, secondary marker for verification, and a senior marker for final moderation. Set marking deadlines - if the exam finishes on Monday, perhaps deadline is Sunday next week. Enable automatic cross-checking where a percentage of scripts are reviewed by a second marker for consistency."

**[SCREEN RECORDING - Quality Assurance]**
- Set threshold: flag scripts that vary significantly between markers
- Configure statistical review: average marks per marker
- Enable anomaly detection for unusual patterns

**[VOICEOVER]:**  
"Quality assurance is built-in. If two markers assign vastly different scores to the same script, the system flags it. You can review statistical reports showing each marker's average - if one teacher consistently marks 20% higher than others, that's visible for discussion."

**[ON-SCREEN TEXT]**

## [05:00-05:45] Advanced Features & Best Practices (45 sec)

**[VISUAL]** Tips appearing on screen with supporting animations

**[VOICEOVER]:**  
"Here are some advanced features that make exam management even smoother."

**[ON-SCREEN BULLET POINTS - with animated appearance]**
1. **Exam Templates:** Create templates for recurring exams (end of term, mock exams) and reuse them each academic cycle - just update dates.

2. **Special Circumstances:** Flag students with special exam requirements - extra time, separate room, reader assistance - and the system reminds invigilators.

3. **Statistical Analytics:** Generate detailed performance analytics showing subject difficulty, class performance trends, and individual student progress over time.

4. **Moderation Trail:** Complete audit trail of who marked what, when changes were made, and final approvals for accountability and quality assurance.

5. **Comparative Analysis:** Compare current exam results against previous terms to identify learning gaps or concerning trends requiring intervention.

**[VOICEOVER]:**  
"Pro tip: Create exam templates at the start of the year for your major exams - first term, second term, third term. Each new cycle, duplicate the template and update dates. This saves substantial setup time.

Another tip: Use the statistical reports to identify students who might need extra support. If a student's scores are declining, flag them for intervention early.

And remember: the complete moderation trail means you have documentation of the entire process for accreditation and transparency."

## Production Notes

**Camera/Screen Recording:**
- Record at 1920x1080 resolution minimum
- Show full exam configuration windows during setup steps
- Zoom in on marking scheme details for clarity
- Capture dashboard metrics and charts clearly

**Graphics & Animations:**
- Animate progress bars showing marking completion
- Use color coding: Green (complete), Yellow (in progress), Red (issues)
- Create smooth transitions between setup steps
- Highlight important configuration options before clicking

**Audio:**
- Background music: 20-30% volume during voiceover
- Voiceover pace: Professional, conversational (130-150 words per minute)
- Sound effects: Soft notification ping when results published, gentle success chime

**Text Overlays:**
- Use 24pt minimum font size
- Display step numbers clearly (Step 1, Step 2, Step 3)
- Keep overlays on screen for 3-5 seconds
- Use consistent color scheme matching school branding

**Timing Cues:**
- Pause on important configuration screens for 2-3 seconds
- Show cursor movement clearly before clicking
- Allow dashboards to display for adequate viewing time
- Sync visual transitions with voiceover pacing
