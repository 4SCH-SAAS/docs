## Format Specifications

All scripts follow a consistent, professional format with:

### Standard Section Structure
1. **[00:00-00:15] INTRO** - Feature introduction and value proposition
2. **[TIME] Why It Matters** - Business context (30-45 seconds)
3. **[TIME] Getting Started** - Step-by-step setup (60-90 seconds)
4. **[TIME] Main Features** - Detailed walkthroughs (90-120 seconds)
5. **[TIME] Advanced Features** - Pro tips and best practices (45-75 seconds)
6. **[TIME] OUTRO** - Call-to-action and branding (15-30 seconds)

### Production Elements in Every Script
- ✅ Detailed VISUAL guidance for screen recording
- ✅ MUSIC cues with volume specifications
- ✅ VOICEOVER pacing recommendations (130-150 wpm)
- ✅ ON-SCREEN TEXT overlay specifications
- ✅ Sound effects guidance (subtle, purposeful)
- ✅ Screen recording zoom and timing notes
- ✅ Graphics and animation specifications
- ✅ Audio quality standards (44.1kHz, 16-bit, stereo)
- ✅ Text overlay standards (24pt minimum, 3-5 second duration)
- ✅ Production notes section
- ✅ SEO metadata (title, description, tags, keywords)

### Complete SEO Metadata Package
Each script includes:
- **Title:** Action-verb based, feature-specific, platform-named
- **Description:** 150-160 characters with clear value proposition
- **Tags:** 8-12 relevant tags
- **Keywords:** 10-15 long-tail and primary keywords
