## [01:00-02:15] Creating Discount Categories (75 sec)

**[VISUAL]** Screen recording: Discount configuration

**[VOICEOVER]:**  
"Let's set up your discount system. From the admin dashboard, navigate to Finance → Discounts & Exemptions → Discount Categories."

**[SCREEN RECORDING - Step 1: Create Discount Type]**
- Click "New Discount Category"
- Enter category name (e.g., "Sibling Discount")
- Select discount type: Percentage or Fixed Amount
- Set discount value (e.g., 10% for second child, 15% for third)
- Apply to which fee items: Tuition only or all items

**[VOICEOVER]:**  
"Step one: Create a discount category. Give it a clear name. Choose if it's a percentage discount (10% off) or fixed amount (₦50,000 off). For sibling discounts, set different percentages for each child - perhaps 10% for second, 15% for third. Decide which fees are discounted - typically tuition only, not registration."

**[SCREEN RECORDING - Step 2: Define Eligibility Criteria]**
- Set conditions for who qualifies
- Example sibling discount: 'Two or more students from same family enrolled simultaneously'
- Example staff discount: 'Parent is current school employee'
- Example merit scholarship: 'Student achieved 80% or higher in entrance exam'
- Option to set duration: Apply to which academic year/term

**[VOICEOVER]:**  
"Step two: Define eligibility. For sibling discounts, specify that two or more children from the same family must be enrolled at the same time. For staff discounts, employee status is the criterion. For merit scholarships, set the achievement threshold - perhaps 80% on entrance exam. You can set discounts to apply annually or just specific terms."

**[SCREEN RECORDING - Step 3: Set Application Method]**
- Automatic: System applies discount when eligibility is met
- Manual: Admin reviews and approves
- Hybrid: System suggests, admin confirms
- Show automatic vs manual trade-offs (speed vs control)

**[VOICEOVER]:**  
"Choose how discounts are applied. Automatic application means the system applies discounts instantly when eligibility criteria are met - fast and consistent. Manual application means your administrator reviews and approves each discount - more control but slower. Most schools use automatic for routine discounts like sibling discounts, manual for scholarships where applications must be reviewed."

**[SCREEN RECORDING - Step 4: Configure Limits & Caps]**
- Set maximum discount per student (e.g., "Max 15% total discount")
- Set school-wide discount cap (e.g., "No more than 30% of students with discounts")
- Configure rollover: Can unused discount apply to next term?
- Set notification thresholds: Alert admin if discount exceeds limit

**[VOICEOVER]:**  
"Configure limits to maintain financial sustainability. You might cap total discount per student at 15% - so a student doesn't get both sibling discount and merit scholarship simultaneously exceeding 15%. Set school-wide caps - perhaps no more than 30% of students have significant discounts. This prevents the discount system from becoming unsustainable."

**[ON-SCREEN TEXT]**

## [02:15-03:45] Managing Different Discount Types (90 sec)

**[VISUAL]** Different discount scenarios being configured

**[VOICEOVER]:**  
"Let's explore the different types of discounts and how to manage each one."

**[SCREEN RECORDING - Sibling Discounts]**
- Show sibling discount configuration
- Set: 1st child = full price, 2nd = 10% discount, 3rd = 15% discount
- Automatic application when second child enrolls
- Example: Two children in school, third enrolls mid-year
- System calculates: 3rd child gets 15% discount automatically
- Adjust if family circumstances change

**[VOICEOVER]:**  
"Sibling discounts encourage family enrollment. Typically, the first child pays full price, the second gets 10% off, the third gets 15% off. The system applies these automatically when siblings enroll. If a family can't afford full price and multiple children need to attend, this softens the burden."

**[SCREEN RECORDING - Staff Discounts]**
- Show staff discount configuration (e.g., 25% discount for staff children)
- Verify staff member status before applying
- Option to apply to spouse's family or just direct staff
- Show renewal process annually to verify continued employment

**[VOICEOVER]:**  
"Staff discounts recognize employee benefits. A 25% discount for staff children is common. The system verifies the employee's current status before applying discounts. Discounts renew annually when staff status is confirmed - so if someone leaves the school, their discount ends the next term."

**[SCREEN RECORDING - Merit Scholarships]**
- Show merit scholarship creation (e.g., "Academic Excellence Scholarship")
- Set eligibility: Entrance exam 85%+, WAEC result grade A
- Select scholarship value: Full tuition, 50% tuition, or fixed amount
- Configure approval workflow
- Show application submission by students

**[VOICEOVER]:**  
"Merit scholarships reward excellence. Set clear criteria - perhaps students scoring 85% or higher on entrance exams or achieving grade A on external exams. Define scholarship value - full tuition for top performers, 50% for strong performers. Require application and review to ensure fairness."

**[SCREEN RECORDING - Financial Hardship Exemptions]**
- Show hardship exemption creation
- Application process: Parent submits request with supporting documents
- Review workflow: Submitted → Under Review → Approved/Denied
- If approved, set exemption type: Full waiver, Partial waiver, or extended payment plan
- Provide audit trail: Who approved, why, for how long

**[VOICEOVER]:**  
"Financial hardship exemptions are critical for inclusive education. Parents submit applications with documentation. Your committee reviews circumstances and decides. You might fully waive fees for extreme hardship, offer partial waivers for moderate difficulty, or create extended payment plans to spread costs. The system tracks everything for accountability."

**[SCREEN RECORDING - Religious/Community Waivers]**
- Show option to create special waivers for specific groups
- Example: Clergy families get discount
- Example: Community service participants get fee credit
- Configure any other school-specific discount categories

**[VOICEOVER]:**  
"Many schools have additional discount categories. Clergy families might get clergy discounts. Students performing community service might earn fee credits. Religious schools might offer discounts to members. You can create any discount categories relevant to your school's mission."

## [05:00-05:45] Best Practices & Transparency (45 sec)

**[VISUAL]** Tips and transparency principles being highlighted

**[VOICEOVER]:**  
"Here are best practices for managing discounts in ways that are both fair and sustainable."

**[ON-SCREEN BULLET POINTS - with animated appearance]**
1. **Clear Policies:** Publish your discount policies openly so all families understand eligibility and expectations.

2. **Standardized Criteria:** Use objective criteria (test scores, family income bands) rather than subjective decisions to ensure fairness.

3. **Regular Audits:** Review discount distribution regularly to identify and address any bias or inconsistency.

4. **Financial Planning:** Budget for expected discounts so the school can sustain them long-term.

5. **Privacy Protection:** Keep discount information confidential - don't publicly label students as scholarship or hardship cases.

6. **Periodic Review:** Evaluate annually whether your discount system is achieving your goals and is financially sustainable.

**[VOICEOVER]:**  
"Pro tip: Publish your discount policies openly. Families should know upfront what discounts are available and how to qualify. This builds trust and ensures everyone has fair access to opportunities.

Another tip: Use objective criteria. Rather than subjective scholarship decisions, use clear thresholds like 'students scoring 85% on entrance exam.' This prevents favoritism and ensures consistency.

And remember: The best discount systems balance accessibility with financial sustainability. Monitor impact regularly and adjust if needed. Your goal is equity - ensuring deserving students aren't excluded by inability to pay - while maintaining the school's financial health to serve all students well."
