## 🎨 Production Standards

### Audio/Voiceover
- Professional, clear enunciation
- Varied pacing (slower for complex, faster for overviews)
- Consistent volume and tone throughout
- Natural pauses for emphasis
- Appropriate background music levels

### Visual Design
- 1080p minimum resolution (4K recommended)
- Smooth, deliberate cursor movements
- Strategic zoom-ins on UI elements
- Color-coded highlights for important information
- Professional, accessible color palette
- Consistent branding and watermarks

### Captions & Accessibility
- Full captions for all spoken content
- Synchronized timing with voiceover
- Sound effect descriptions
- WCAG AA color contrast compliance
- Screen reader friendly descriptions

### Timing & Pacing
- Generous pauses (1-3 seconds) between concepts
- Text overlays appear 2-3 seconds before mention
- Screen actions match voiceover narration
- Smooth transitions (0.3-0.5 seconds)
- Realistic software interactions
