Set parameters: maximum file size, allowed file types, and late submission policy. For this assignment, files must be PDF or Word format, up to 10 MB, and late submissions are accepted with a 5% daily penalty.

Attach supporting resources. If students need a guide or reference material, upload it here so they have access when completing the assignment.

Create a rubric to clarify grading criteria. Define what 'excellent,' 'good,' 'fair,' and 'poor' mean for each aspect. Assign points to each criterion. With a clear rubric, students know expectations and grading is consistent.

Preview how the assignment appears to students. Make sure the description is clear and all attachments are present."
