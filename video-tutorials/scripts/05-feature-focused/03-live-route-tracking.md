**Visual Cues:**

**Voiceover Script:**
"Welcome to one of the most requested features for school safety and parent peace of mind—Live Route Tracking. This feature uses GPS technology to provide real-time visibility of school buses as they travel their routes. Parents receive live updates about pick-up times and arrival estimates, reducing anxiety and improving communication.

In this tutorial, you'll learn how to set up routes, monitor buses in real-time, and understand how parents access this information through their own interface."

### Feature Overview (0:45 - 1:45)

**Visual Cues:**
- Split-screen showing admin interface and parent interface
- Key features highlighted with animations:
  - Real-time bus location
  - ETA calculations
  - Route visualization
  - Student check-in/check-out
  - Alert notifications
  - Trip history

**Voiceover Script:**
"Live Route Tracking has two sides. The administrator side, which we'll focus on, allows you to monitor all buses, manage routes, and send alerts. The parent side lets families track their student's bus in real-time and receive notifications.

Key features include live GPS coordinates updated every 30 seconds, automatic ETA calculations that account for traffic, visual route display on interactive maps, and timestamp records of student boarding and drop-off. If there's a delay or incident, you can send alerts to affected parents.

Parents see their assigned bus on a map, the number of stops ahead, and an estimated arrival time. They receive notifications when the bus is approaching, when their student boards, and when the bus arrives at their school or stop."

**Production Notes:**

### Step 1: Setting Up Routes (1:45 - 2:45)

**Visual Cues:**
- Screen recording: Navigate to Transport Management
- Click "Routes" or "Bus Management"
- Show route creation form with fields:
  - Route name/number
  - Assigned bus
  - Start/end times
  - Stops (addresses)
  - Assigned students
  - Driver information

**Voiceover Script:**
"First, let's set up your routes. From the admin dashboard, go to Transport Management or Bus Operations. Click 'Routes' to access route management.

To create a new route, click 'New Route.' You'll enter a route name or number—something like 'Route 5 - North Campus' for easy identification.

Next, assign a bus to the route. Select from your fleet of available buses. The system tracks each bus's GPS capability, ensuring you're using equipped vehicles.

Add your stops in order. For each stop, enter the street address. The system will automatically calculate distances and optimize timing. You can also manually drag and drop stops to reorder them if needed.

Assign the students who ride this route. You can filter by grade, address, or manually select individual students. The system handles multiple guardian accounts per student, so all authorized family members receive tracking updates.

Finally, assign a driver or transport staff member. They'll receive alerts about the route and have access to student check-in functions."

**Production Notes:**
- Record form entry clearly and deliberately
- Show map preview updating as stops are added
- Demonstrate drag-and-drop stop reordering
- Zoom in on student selection interface
- Show validation messages and confirmations
- Include tooltip explanations for each field

### Step 2: Starting Live Tracking (2:45 - 3:45)

**Visual Cues:**
- Screen recording: Route list with "Start Route" button
- Click to start route
- Show map with live bus position
- Display status changing from "Scheduled" to "In Transit"
- Show student roster with check-in column

**Voiceover Script:**
"When it's time for the route to run, open the route and click 'Start Route.' This activates GPS tracking and begins real-time updates.

Once the route is live, you'll see a map showing the bus's current location with a moving pin. The system updates the bus position every 30 seconds, providing near-real-time visibility. You'll also see the route path, all scheduled stops, and landmarks nearby.

Alongside the map, you'll see a checklist of students assigned to this route. As the bus arrives at each stop, the driver uses the mobile app or scan interface to check in each student. Checked-in students appear with a green checkmark.

On the right panel, you'll see key information: current time, elapsed time, next stop address, distance to next stop, and estimated time of arrival at the next stop. This information automatically updates as the bus progresses."

**Production Notes:**
- Show live map with moving bus animation
- Highlight next stop with color
- Display real-time ETA updates
- Show student check-in notifications arriving
- Use smooth map panning as route progresses
- Include audio notification sound for check-ins

### Step 3: Monitoring and Alerts (3:45 - 4:45)

**Visual Cues:**
- Show monitoring dashboard with:
  - All active routes displayed
  - Route metrics (on schedule, delayed, completed)
  - Alert notification panel
- Demonstrate creating an alert:
  - Click "Send Alert"
  - Select alert type (delay, breakdown, incident)
  - Choose recipient groups
  - Send alert

**Voiceover Script:**
"The monitoring dashboard shows all active routes at a glance. Each route displays its status—on schedule, delayed, or completed. You can see the number of students checked in, stops remaining, and overall progress.

If something unexpected happens—a traffic jam, mechanical issue, or accident—you can immediately send an alert. Click the 'Send Alert' button on the route. Choose the alert type: delay, mechanical breakdown, incident, or custom message.

Select which parent groups should receive the alert. You can notify parents of students on this bus, all school parents, or specific groups. Write a brief, reassuring message explaining the situation and expected resolution time.

When you send the alert, parents receive an immediate notification on their phones. They'll see the delay reason and updated ETA. This transparency builds trust and reduces anxiety."

**Production Notes:**
- Show dashboard with multiple routes
- Zoom in on alert creation form
- Display alert notification as it appears on parent phone
- Show alert history log
- Use warning color for delay/incident alerts
- Include example alert messages

### Step 4: Route Completion and Reporting (4:45 - 5:30)

**Visual Cues:**
- Show route progress completion
- Display "End Route" button
- Show completion summary with:
  - Total travel time
  - Number of students transported
  - Any incidents/notes
  - Completion timestamp
- Display route history/analytics

**Voiceover Script:**
"As the route reaches its final destination and the last student is dropped off, click 'End Route.' This stops the live tracking and creates a completion record.

The system generates a route summary showing total travel time, the number of students successfully transported, any recorded incidents or delays, and completion timestamp. This data is important for accountability and record-keeping.

You can access route history and analytics to identify patterns. For example, if a particular route is consistently delayed, you might adjust the schedule or modify stops. The system stores all tracking data for compliance and safety documentation, which is invaluable if you ever need to review what happened on a specific day."

**Production Notes:**
- Show route completion animation
- Display summary screen with key metrics
- Show analytics dashboard
- Highlight trends and patterns
- Use professional data visualization

### Best Practices (5:30 - 5:50)

**Visual Cues:**
- Slide-based best practices
- Icons for each practice
- Color-coded importance

**Voiceover Script:**
"Here are essential best practices for safe route tracking:

First, regularly verify your GPS equipment is functioning. Test tracking quarterly to ensure accuracy.

Second, establish clear driver protocols for student check-in. Consistency matters for accurate data.

Third, communicate with parents about how to access live tracking. Some may not know this feature exists.

Fourth, set realistic ETAs. Include time for traffic, stops, and unexpected delays.

Finally, keep detailed records of any incidents or unusual events. This documentation is critical for safety audits."

**Production Notes:**

- Use professional color palette
