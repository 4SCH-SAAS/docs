**[VOICEOVER]:**  
"To correct a single attendance record, navigate to your class attendance view. You see a calendar and a grid showing which students were present or absent each day.

Found an error? Click on the attendance cell. The system shows the current status and who marked it. Click 'Edit Record' to change it.

Select the correct status: Present, Absent, Leave, or Medical Leave. Then select the reason for the correction from the dropdown. Was it a data entry error? Was the student actually present? Did they have approved leave?

Add a note if needed to explain the correction. Save, and the system logs the change with a timestamp and the person making the correction.

The corrected record now reflects the accurate attendance."

## [01:50-02:45] Bulk Attendance Correction (55 sec)

**[VISUAL]**

  - Field 2: "Select Date" - Calendar picker showing 12 Feb 2025
  - Field 3: "Current Status" - Dropdown showing Absent (no attendance marked)
  - Field 4: "New Status" - Dropdown set to Present
  - Field 5: "Reason for Bulk Correction" - "Forgotten Attendance Marking"
  - Field 6: "Additional Notes" - "Mr. Adeyemi was absent on 12th Feb but left attendance for substitute teacher who didn't complete marking. All 45 students were in class."
  - Preview option: "Show Affected Students" button
- User clicks "Show Affected Students"
  - List appears showing 45 students in JSS2A
  - All currently marked Absent on 12 Feb
  - Message: "These 45 students will be marked Present"
  - "Confirm" button enabled
- User clicks "Confirm"
- Processing:
  - Progress bar: "Correcting 45 attendance records..."
  - Message: "Updating attendance record…"
  - Completion: "Bulk correction complete!"
  - Summary: "45 records changed from Absent to Present on 12 Feb"
  - System automatically sends notification to teacher: "Attendance for your JSS2A class on 12 Feb has been corrected"

**[VOICEOVER]:**  
"For corrections affecting multiple students - like an entire class's forgotten attendance - use bulk correction.

Go to Bulk Correction and select the class, the date, and what you're changing. If the entire JSS2A class was marked absent on February 12th but actually attended, correct all 45 records at once.

The system shows you all affected students so you can verify you're correcting the right records. Add a note explaining the bulk correction so there's a clear audit trail.

Confirm, and the system updates all 45 records instantly. No need to correct students individually. The affected teacher is notified of the correction so they're aware of the change."

**[VOICEOVER]:**

The system shows the correction request: what changed, who submitted it, and why. An admin can approve or reject it with feedback.

Once approved, the system maintains a complete audit trail. It shows the original record, when it was corrected, who made the correction, and who approved it. This transparency is valuable for compliance and investigations.

The corrected attendance now appears in all reports, student records, and the parent portal. Attendance percentages update automatically. Your data is now accurate throughout the system."
