## [02:15-03:30] Advanced Grading Features (75 sec)

**[VISUAL]**
- Feature 1: Batch Grading
  - Display: Quick grade entry for multiple students at once
  - Simple form showing:
    - Student name | Score | Grade
    - Input fields for score percentage
    - Dropdown for letter grade
  - Use case: Quick formative quizzes where you just need a score without detailed rubric feedback
  - Bulk import option: Upload grades from Excel

- Feature 2: Grade Curves & Adjustments
  - Scenario: Class average is 62%, lower than expected
  - Tool: "Adjust Grades" option
  - Adjustment method 1: Add points across board
    - "Add 8 points to all grades to raise average to 70%"
    - Preview showing before/after
    - Adjust only specific criteria if needed
  - Adjustment method 2: Curve grades
    - Highest score becomes 100%, others scale proportionally
    - Visual showing distribution shift
  - Teacher reviews and approves adjustment
  - All students notified of adjustment
  - Comment added explaining adjustment: "Class average was low. Added 8 points to reflect question ambiguity."

- Feature 3: Grading Standards
  - Pre-defined rubric templates:
    - "Standard Academic Rubric" - 4 levels, 25 points each
    - "Effort-Based Rubric" - emphasis on improvement
    - "Skills-Based Rubric" - focusing on specific competencies
    - "Custom Rubric" - create your own
  - Import rubric from previous assignments
  - Copy and modify existing rubric
  - Share rubric with colleagues

- Feature 4: Student Samples
  - Feature: Show exemplar submissions
  - Example shown:
    - "Excellent Sample" submission displayed
    - "Good Sample" submission for comparison
    - "Fair Sample" for clarity
  - Helps maintain consistency across students
  - New teachers benefit from seeing quality examples

- Feature 5: Grading Comments Library
  - Pre-written feedback comments stored
  - Categories: Strengths, Areas to Improve, Encouragement
  - Examples:
    - Strengths: "Well-organized response," "Clear thinking," "Excellent supporting evidence"
    - Improve: "Add more detail," "Check your math," "Strengthen your argument with examples"
    - Encouragement: "Great effort," "You're improving," "Keep practicing this skill"
  - Click to insert, then customize for individual student
  - Saves time while maintaining personalization
  - Build library over time as you develop favorites

**[VOICEOVER]:**  
"Beyond the rubric interface, 4SCH offers advanced grading features. For quick quizzes, use batch grading to enter scores for multiple students on one screen without detailed rubrics.

Sometimes class performance warrants grade adjustments. If most students struggled with a question, you can add points to all grades or curve them mathematically. The system shows the impact before you apply it.

Use pre-built grading rubrics from the library, or create custom ones. Share effective rubrics with colleagues so everyone uses consistent standards.

Some teachers include student samples - examples of excellent, good, and fair work. This helps you stay consistent and shows students what quality looks like.

To speed up feedback, build a comments library. Common feedback phrases stored and ready to insert. You still personalize each student's feedback, but you're not typing the same comment 45 times."

**[ON-SCREEN TEXT]**
