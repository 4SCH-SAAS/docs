## [01:00-02:15] Setting Up Report Card Templates (75 sec)

**[VISUAL]** Screen recording: Report card template configuration

**[VOICEOVER]:**  
"Before generating report cards, you need to set up your templates. These define what information appears on cards and how it's organized."

- Navigate to Academic → Report Cards → Templates
- View existing templates or click "Create New Template"
- Select template category: Primary School, Secondary School, Higher Education

**[VOICEOVER]:**  
"From the admin dashboard, go to Academic → Report Cards → Templates. You'll see pre-built templates for primary, secondary, and higher education. You can use these as-is or customize them completely."

**[SCREEN RECORDING - Step 2: Configure Template Sections]**
- Show template builder interface
- Drag sections: Academic Performance, Competencies, Behavior, Attendance, Comments
- Rearrange sections via drag-and-drop
- Toggle sections on/off based on school needs

**[VOICEOVER]:**  
"The template builder uses drag-and-drop. You can include multiple sections: Academic Performance showing grades by subject, Competencies displaying skill development, Behavior tracking conduct and participation, Attendance showing days present and absent, and Comments giving teacher observations."

**[SCREEN RECORDING - Step 3: Configure Academic Performance Section]**
- Expand Academic Performance settings
- Choose grading system: Points (0-100), Grades (A-F), Or custom
- Select which subjects appear
- Configure columns: Subject, Continuous Assessment, Exam Score, Total, Grade, Position, Class Average

**[VOICEOVER]:**  
"For academic performance, choose your grading system. 4SCH supports points, letter grades, or custom scales. Select which subjects display. **[SCREEN RECORDING - Step 5: Configure Behavior & Attendance]**

## [02:15-03:45] Generating Report Cards (90 sec)

**[VISUAL]** Report card generation process showing progress

**[VOICEOVER]:**  
"Once templates are configured, generating report cards is straightforward. Let's walk through the process."

**[SCREEN RECORDING - Step 1: Initiate Generation]**
- Navigate to Academic → Report Cards → Generate
- Select academic term (e.g., "First Term 2024")
- Select classes to generate for (can be all classes or specific ones)
- Choose template (use different templates for different class levels if desired)

**[VOICEOVER]:**  
"Go to Generate Report Cards. Select the academic term - first term, second term, etc. Choose which classes you're generating for - maybe just secondary classes this week, primary next week. Select your template."

**[SCREEN RECORDING - Step 2: Configure Generation Options]**
- Toggle options: Include comments, Include attendance, Include behavior, Include competencies
- Set name format: Student's legal name or nickname
- Choose format: Digital PDF, Web-based, Print-ready
- Select language: English, French, or school's preferred language

**[VOICEOVER]:**  
"Configure options. Do you want teacher comments included? Attendance records? Behavioral assessments? You decide what appears. Choose your format - PDF for printing or email distribution, web-based for digital access, or print-ready optimized for actual printing on colored stock."

**[SCREEN RECORDING - Step 3: Review Data Completeness]**
- System checks if all required fields are populated
- Shows warning icon next to incomplete entries
- Example: Missing grades for Math in JS1A
- Option to skip incomplete records or stop and fix

**[VOICEOVER]:**  
"Before generation, the system checks data completeness. If a teacher hasn't entered grades for a subject yet, that's flagged. You can proceed and generate partial cards, or stop and follow up with the teacher to complete missing grades. This prevents incomplete report cards reaching parents."

**[SCREEN RECORDING - Step 4: Preview & Generate]**
- Show preview of sample report card
- Display formatting and layout
- Review student data accuracy
- Click "Generate Report Cards"
- Progress bar showing generation status

**[VOICEOVER]:**  
"Preview a sample report card. Verify the layout looks professional and all information is accurate. Then click 'Generate.' Depending on school size, this might take seconds to a few minutes. For a school with 500 students, it's typically done in under a minute."

**[SCREEN RECORDING - Step 5: Review Generated Cards]**
- Show list of generated report cards
- Display generation summary: 450 cards generated successfully, 2 with warnings
- Option to view individual cards
- Download or delete options

**[VOICEOVER]:**  
"Once generation completes, you get a summary. 450 cards generated successfully, 2 with data warnings you might want to verify. You can view individual cards, download them as PDFs, or export the entire batch."

## Production Notes

**Camera/Screen Recording:**
- Record at 1920x1080 resolution minimum
- Zoom in on report card layouts for detailed viewing
- Show full template builder interface clearly
- Capture data tables and performance metrics legibly

**Graphics & Animations:**
- Animate progress bars during generation
- Use checkmarks for completed sections
- Create visual transitions between template components
- Highlight section headers as they're being configured

**Audio:**
- Background music: 20-30% volume during voiceover
- Voiceover pace: Professional, conversational (130-150 words per minute)
- Sound effects: Subtle notification sound when cards are generated, gentle paper rustling

**Text Overlays:**
- Use 24pt minimum font size for readability
- Display step numbers prominently
- Keep overlays on screen for 3-5 seconds
- Use consistent color scheme

**Timing Cues:**
- Pause on template preview screens for clear viewing
- Allow progress bars to complete visibly
- Show cursor movement clearly before clicking
- Sync visual transitions with voiceover mentions
