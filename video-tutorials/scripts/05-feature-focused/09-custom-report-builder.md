## [01:00-02:30] Building Your First Custom Report (90 sec)

**[VISUAL]** Screen recording: Report builder interface

**[VOICEOVER]:**  
"Let's create a custom report. From the admin dashboard, navigate to Analytics → Custom Reports → Build New Report."

**[SCREEN RECORDING - Step 1: Select Data Source]**
- Click "Create New Report"
- Choose data source: Academic Data, Financial Data, Attendance Data, All Data
- Select specific entities: All students, specific classes, specific date range
- Preview available fields

**[VOICEOVER]:**  
"Step one: Select your data source. Do you want academic data (grades, exams), financial data (fees, payments), attendance data, or a combination? Choose which students to include - all or filtered to specific classes? Select date range - this term, this year, or custom dates?"

**[SCREEN RECORDING - Step 2: Choose Report Type]**
- Click "Report Type"
- Show options: Summary Report, Comparison Report, Trend Analysis, Detailed List
- Summary: Aggregate data (class averages, totals)
- Comparison: Side-by-side comparison (last year vs this year)
- Trend: Changes over time (progress through year)
- Detailed List: Individual records with filtering

**[VOICEOVER]:**  
"Step two: Choose your report type. A summary report aggregates data - perhaps average exam scores across all classes. A comparison report shows year-over-year or term-over-term changes. Trend analysis shows how something evolves over time - like improving or declining attendance. Detailed lists show individual records with sorting and filtering."

**[SCREEN RECORDING - Step 3: Select Fields & Metrics]**
- Click "Add Fields"
- Choose what appears in report
- Example fields: Class, Subject, Average Score, Number of Students, Pass Rate
- Drag fields to order appearance
- Configure calculations: Sum, Average, Percentage, Count

**[VOICEOVER]:**  
"Step three: Select which fields appear in your report. You might want: Class name, Subject, Average exam score, Number of students, Pass rate percentage. Drag to order how they appear. Configure calculations - do you want sums, averages, counts, or percentages?"

**[SCREEN RECORDING - Step 4: Apply Filters]**
- Click "Add Filters"
- Filter by class, subject, date range, achievement level, attendance threshold
- Example: "Show only classes with less than 70% average in Mathematics"
- Stack multiple filters (AND logic)

**[VOICEOVER]:**  
"Step four: Apply filters to focus your report. Maybe you only want to see Math results, or results for secondary classes only, or results from students with 80% attendance or better. Stack multiple filters - the report shows only data meeting all criteria."

**[SCREEN RECORDING - Step 5: Add Visualizations]**
- Click "Add Chart"
- Choose chart type: Bar Chart, Line Graph, Pie Chart, Table
- Configure: What's on X-axis? Y-axis? What data is plotted?
- Example: Bar chart showing average by subject
- Example: Line graph showing attendance trend over term

**[VOICEOVER]:**  
"Step five: Add visualizations. A bar chart might show average exam scores by subject, making it obvious which subjects need support. A line graph might show attendance trend - is it improving or declining? A pie chart might show fee payment status distribution. Visualizations make data meaningful."

**[SCREEN RECORDING - Step 6: Configure Report Options]**
- Set report title and description
- Configure sort order (by class name, by average score, etc.)
- Set pagination (how many rows per page)
- Configure formatting: Colors, fonts, number of decimal places

**[VOICEOVER]:**  
"Step six: Configure options. Give your report a clear title like 'Mathematics Performance by Class.' Add a description explaining what's shown. Set sort order - perhaps by average score from highest to lowest. Configure how it displays - colors, decimal places, etc."

## [06:15-07:00] Best Practices & Tips (45 sec)

**[VISUAL]** Tips appearing on screen with supporting graphics

**[VOICEOVER]:**  
"Here are best practices for getting maximum value from custom reports."

**[ON-SCREEN BULLET POINTS - with animated appearance]**
1. **Focus on Action:** Create reports that drive decisions. Avoid data for data's sake.

2. **Regular Rhythm:** Generate key reports on regular schedules - weekly, monthly, quarterly - so trends are visible.

3. **Share Insights:** Don't hoard reports. Share relevant data with teachers and department heads so everyone understands performance.

4. **Compare Context:** Compare current performance against previous years, targets, and peers to understand significance.

5. **Update Regularly:** Review and update reports as school goals evolve. Last year's critical reports might not be relevant this year.

6. **Data Quality:** Ensure underlying data is accurate. Garbage in = garbage out. Validate data entry processes.

**[VOICEOVER]:**  
"Pro tip: Create reports that drive actual decisions. Don't create reports just because you can. If you won't act on the information, don't spend time generating it.

Another tip: Generate key reports consistently. A monthly fee collection report helps track trends. Weekly attendance reports help spot emerging problems. Consistent rhythm helps identify patterns.

And remember: Data is meaningless without context. Comparing current performance against previous years, against your targets, and against similar schools helps you understand what the numbers mean."

## Production Notes

**Camera/Screen Recording:**
- Record at 1920x1080 resolution minimum
- Zoom in on chart details for clarity
- Show data tables with readable numbers
- Capture dashboard displays prominently
- Show drill-down functionality clearly

**Graphics & Animations:**
- Animate chart generation (bars rising, lines drawing)
- Use color coding to highlight important data points
- Create smooth transitions between filter states
- Animate data flowing into visualizations
- Use arrow animations to show drill-down paths

**Audio:**
- Background music: 20-30% volume during voiceover
- Voiceover pace: Professional, conversational (130-150 words per minute)
- Sound effects: Subtle data processing sound during report generation, notification sound for alerts

**Text Overlays:**
- Use 24pt minimum font size
- Display step numbers prominently
- Show percentage symbols clearly (%)
- Use consistent color scheme
- Display metric values legibly on charts

**Timing Cues:**
- Pause on chart displays for 3-5 seconds for absorption
- Show report generation process visibly
- Allow data drill-down to display fully
- Highlight alert notifications when they appear
- Sync visual transitions with voiceover mentions
