## [01:00-02:15] Creating Your Fee Structure (75 sec)

**[VISUAL]** Screen recording: Fee structure configuration wizard

**[VOICEOVER]:**  
"Let's create a complete fee structure. From the admin dashboard, navigate to Finance → Fee Management → Fee Structures."

**[SCREEN RECORDING - Step 1: Define Fee Components]**
- Click "Create New Fee Structure"
- Name the structure (e.g., "Secondary School 2024")
- Define academic year/term
- Select applicable classes/forms

**[VOICEOVER]:**  
"Step one: Create a new fee structure. Give it a clear name like 'Secondary School 2024.' Select which academic year and term this applies to. Choose which classes will use this structure - perhaps all secondary forms or just specific classes with different fee structures."

**[SCREEN RECORDING - Step 2: Add Fee Components]**
- Click "Add Fee Item"
- Enter fee name: Tuition, Registration, Exam, Library, Sports, Transportation, etc.
- Set amount in Naira
- Mark as mandatory or optional
- Select frequency: One-time, Per Term, Annual

**[VOICEOVER]:**  
"Step two: Add fee items. These are the individual charges making up total fees. Create items for each cost: Tuition, Registration Fee, Examination Fee, Library Development, Sports Fund, Facility Fee. For each item, set the amount and frequency. Is Tuition charged per term? Is Registration a one-time annual fee? Mark each as mandatory or optional."

**[SCREEN RECORDING - Step 3: Configure By Student Category]**
- Show option to set different fees for different categories
- Example: Day students vs Boarding
- Example: Different tuition by class level (Primary costs less than Secondary)
- Show applying different discounts by category

**[VOICEOVER]:**  
"Here's where flexibility shines. You can configure different fees for different student categories. Day students might pay less than boarding students because there's no accommodation cost. Perhaps Primary School has lower tuition than Secondary School. Set up each category with its specific fee structure."

**[SCREEN RECORDING - Step 4: Set Payment Schedule]**
- Click "Payment Schedule"
- Define payment structure: Lump sum or Installments
- If installments: How many? (e.g., 3 installments per term)
- Set installment amounts (equal or graduated)
- Define due dates for each installment

**[VOICEOVER]:**  
"Configure your payment schedule. Do you want the full amount due at once, or split into installments? Many schools split fees into three installments per term - at the start, mid-term, and end of term. You can make installments equal or graduated, perhaps smaller amounts at the start and larger later as parents have more funds."

**[SCREEN RECORDING - Step 5: Configure Penalties & Late Fees]**
- Set late payment penalty (e.g., 5% per month)
- Configure grace period (e.g., 14 days after due date)
- Set escalation: Does penalty increase after 30 days?
- Option to waive penalties in hardship cases

**[VOICEOVER]:**  
"Configure late payment policies. Set a penalty percentage - perhaps 5% per month late. Define a grace period - maybe 14 days after due date before penalties apply. Decide if penalties escalate - 5% per month up to a maximum. And remember, you can always waive penalties for genuine hardship cases."

## [02:15-03:45] Managing Waivers & Discounts (90 sec)

**[VISUAL]** Discount and waiver configuration interface

**[VOICEOVER]:**  
"Real schools recognize that not all families have equal ability to pay. 4SCH's waiver and discount system ensures fair access while maintaining financial sustainability."

**[SCREEN RECORDING - Set Up Discount Categories]**
- Click "Discounts & Waivers"
- Create discount category (e.g., "Sibling Discount")
- Set discount percentage: 10% for second child, 15% for third
- Apply discount to specific fee items (e.g., tuition but not registration)
- Set conditions: How many siblings must be enrolled simultaneously

**[VOICEOVER]:**  
"Create discount categories. A sibling discount might be 10% for a second child and 15% for a third - schools often incentivize family enrollment. Configure which fee items get discounted - perhaps tuition but not registration. Set clear conditions so the system applies them automatically."

**[SCREEN RECORDING - Configure Staff Discounts]**
- Create staff discount policy
- Set percentage for staff children
- Configure partial vs full discounts for different fee items
- Option to extend discount to spouses' families or just direct staff

**[VOICEOVER]:**  
"Many schools offer employee benefits - discounts for staff children. Define what percentage discount staff get and for which children - just children of staff or extended family too? This is configured once and applied automatically to eligible students."

**[SCREEN RECORDING - Scholarship Management]**
- Create scholarship category
- Set scholarship amount: Full tuition, Partial (e.g., 50%), or Specific amount
- Define eligibility criteria: Academic merit, Financial need, Sports, etc.
- Configure approval workflow: Who reviews scholarship requests?

**[VOICEOVER]:**  
"For scholarship students, create a scholarship category. Define the scholarship value - perhaps full fees for top academic performers, 50% for financial need cases, or specific amounts for sports scholarships. Set eligibility criteria and define who approves scholarships - perhaps the principal or a scholarship committee."

**[SCREEN RECORDING - Hardship & Exemptions]**
- Create exemption for specific students or families
- Provide audit trail: Who approved exemption and why?
- Set temporary vs permanent exemptions
- Option to adjust amounts instead of full exemption

**[VOICEOVER]:**  
"Create a hardship exemption process. If a family faces genuine difficulty, you can exempt them fully or partially. The system tracks who approved the exemption and why - maintaining accountability. Exemptions can be temporary (just this term) or permanent, and you can adjust amounts instead of eliminating charges entirely."

**[SCREEN RECORDING - Apply Discounts to Students]**
- Show applying sibling discount when enrolling second child
- System automatically reduces their invoices
- Show overriding discounts if necessary (e.g., scholarship student still gets sibling discount)

**[VOICEOVER]:**  
"The beauty of this system is automation. When you enroll a second child from a family, the system automatically applies sibling discount to their invoices. When a scholarship is approved, those fee items are waived automatically. Manual discounts can be overridden when exceptions are needed."

## Production Notes

**Camera/Screen Recording:**
- Record at 1920x1080 resolution minimum
- Zoom in on fee configuration details for clarity
- Show full invoice samples for clear viewing
- Capture dashboard metrics legibly

**Graphics & Animations:**
- Animate fee additions to show running total
- Use color coding for different fee categories
- Create visual representations of payment schedules (timeline view)
- Highlight discounts and waivers with visual indicators

**Audio:**
- Background music: 20-30% volume during voiceover
- Voiceover pace: Professional, conversational (130-150 words per minute)
- Sound effects: Subtle notification sound when fee structure is published, soft confirmation chime

**Text Overlays:**
- Use 24pt minimum font size
- Display currency in Naira (₦) consistently
- Show percentage signs clearly for discounts
- Use consistent color scheme

**Timing Cues:**
- Pause on fee summaries for clear viewing (3-5 seconds)
- Show calculation examples clearly
- Allow invoice preview to display fully
- Sync visual transitions with voiceover mentions
