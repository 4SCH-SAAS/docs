#### 4. Supporting Information
- Production Notes (equipment, settings, tips)
- Timing Breakdown (how 10 minutes is allocated)
- Content Checklist (QA verification)

## Production Specifications

### Video Format
```
Resolution: 1080p minimum (1920×1080)
Frame Rate: 30fps
Codec: H.264
Aspect Ratio: 16:9
Bitrate: 8-12 Mbps
Format: MP4
```

### Audio Format
```
Sample Rate: 48 kHz
Channels: Stereo
Bitrate: 192 kbps
Quality: Professional (noise-free)
Format: AAC
```

### Captions
```
Format: SRT or VTT
Accuracy: 100% match with voiceover
Sync: Precise timing alignment
Readability: Max 17-20 chars per line
Language: English (can be translated)
```

## Common Questions

**Q: Can I modify these scripts?**  
A: Yes! Adapt them to your specific needs while maintaining quality standards. Update examples or pace to match your style.

**Q: How should I handle updates?**  
A: If 4SCH features change, update the relevant script sections. No need to re-record the entire video.

**Q: Can I translate these scripts?**  
A: Yes! The structure and timing remain the same. Translate voiceover and on-screen text while maintaining pacing.

**Q: What if I need multiple languages?**  
A: Record voiceovers in each language. Visual descriptions remain the same. Consider subtitle tracks for accessibility.

**Q: How do I handle demo data sensitivity?**  
A: Use clearly-marked test/demo data. Use fictional names and amounts. Avoid real student names or personal information.
