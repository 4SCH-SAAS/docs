## [01:30-03:00] Creating and Managing Fee Types (90 sec)

**[VISUAL]** 
- Settings > Finance Configuration screen
- Click on "Fee Types" section
- Form for creating new fee type with fields highlighted:
  - Fee Type Name (e.g., "Tuition Fee")
  - Fee Category (Compulsory/Optional)
  - Due Date setting
  - Late fee percentage (if applicable)
  - Installment options toggle

**[VOICEOVER]:**  
"To create a fee type, navigate to your Admin Dashboard, go to Finance settings, and click 'Add Fee Type'. 

First, enter the fee name - for example, 'Tuition Fee' or 'Transportation'. Choose whether it's compulsory, meaning all students must pay, or optional.

Next, set the due date. You can choose a specific date, end of month, or even have it due immediately. If you want to charge a late fee - say five percent after the due date - enable that option here.

Finally, decide if this fee can be paid in installments. If yes, specify how many installments are allowed and the duration. Save this fee type, and you're ready to apply it to classes."

## [04:30-06:00] Payment Gateway Configuration (90 sec)

**[VISUAL]**

- Click to configure Paystack
- API keys entry form with security indicators
- Test mode vs Live mode toggle
- Currency selection (Nigerian Naira is default)
- Save and verify connection

**[VOICEOVER]:**  
"4SCH supports multiple payment methods to maximize collection options. Let's configure payment gateways so parents can pay conveniently.

Navigate to Settings, then Payment Gateways. You'll see available options: Paystack and Flutterwave for online payments (popular in Nigeria), Remita for bank transfers, plus options for manual bank transfers and cash payments.

For online payments, select Paystack or Flutterwave and enter your API credentials - you'll get these from your merchant account. Toggle between Test Mode for safe testing and Live Mode when ready for real transactions.

Select your school's currency - typically Nigerian Naira for Nigerian schools. Verify the connection with the test button. The system will confirm successful setup.

You can enable multiple gateways simultaneously, giving parents flexibility. Some parents prefer online payments, others use transfer or cash. Supporting multiple methods increases collection rates significantly."
