## Production Guidelines

### Video Format Standards
- **Resolution:** 1080p minimum (1440p preferred)
- **Frame Rate:** 30fps
- **Aspect Ratio:** 16:9
- **Codec:** H.264 (MP4 container)

### Audio Specifications
- **Sample Rate:** 44.1 kHz or 48 kHz
- **Bitrate:** 128 kbps minimum
- **Channels:** Stereo
- **Voiceover Pace:** 130-150 words per minute
- **Microphone:** USB condenser microphone, professional quality

### Visual Elements
- **Color Scheme:** Consistent with 4SCH branding
- **Fonts:** Sans-serif system fonts (Arial, Helvetica, or similar)
- **Icons:** Use consistent icon set throughout series
- **Transitions:** Smooth, professional (avoid excessive effects)
- **Highlights:** Use arrows, circles, and color overlays to emphasize UI elements

### Screen Recording Tips
- **Zoom Level:** 100-150% depending on content
- **Cursor Visibility:** Highlighted/enhanced for clarity
- **Demo Data:** Use realistic examples with Nigerian names, amounts, and contexts
- **Error Scenarios:** Include examples of common mistakes and how to recover
- **Mobile Screens:** Use side-by-side or picture-in-picture display

## Usage & Adaptation

### For Video Production Teams
1. Open the relevant script file
2. Review visual descriptions and create storyboard
3. Prepare demo environment with realistic data
4. Record screen and voiceover
5. Reference production notes for technical setup
6. Include timing marks and transitions per script
7. Add B-roll and animations as described
8. Post-production: color correction, audio mixing, captions

### For Content Updates
- Scripts are dated but version-agnostic for core features
- Update specific UI elements if 4SCH interface changes
- Maintain timing structure and flow
- Keep SEO metadata relevant
- Document changes in version history

### For Localization
- Voiceover scripts can be translated while preserving timing
- Visual descriptions remain the same
- Adjust examples (names, currency) for regional context
- Update contact/support information per region
