# Online Exams - System Overview

**Video Duration:** 8-10 minutes  
**Target Audience:** All users (administrators, teachers, students, parents)  
**Difficulty Level:** Beginner  
**Prerequisites:** Basic understanding of 4SCH platform

---

## Video Objectives

By the end of this video, viewers will:
1. Understand what online exams are in 4SCH
2. Know the key features and benefits
3. Identify which features apply to their role
4. Feel confident to explore the system

### SECTION 2: Key Features Breakdown (2:00 - 4:30)

**[Screen: Feature showcase with icons]**

**Narrator:**
"Let's explore the core features that make this system work:"

#### Multiple Choice Questions (MCQ)

**[Screen: Example MCQ with single answer]**

"Online exams support multiple choice questions. Questions can have a single correct answer - like this math problem where only option B is correct."

**[Screen: Example MCQ with multiple answers]**

"Or multiple correct answers - like this science question where students must select all the prime numbers. The grading is strict - students must select ALL correct options and NO wrong options to earn marks."

#### Question Bank Management

**[Screen: Question bank interface mockup]**

"Teachers and administrators build a question bank - a library of reusable questions organized by:
- Subject
- Class level  
- Difficulty - easy, medium, or hard
- Topic or chapter

Questions can even include images for diagrams, charts, or visual problems."

**[Screen: Excel import animation]**

"Need to add hundreds of questions? Use the bulk import feature. Download the template, fill it with your questions, and upload - done!"

#### Exam Scheduling & Security

**[Screen: Calendar with exam scheduled]**

"Schedule exams with precision:
- Set start date and time
- Set end date and deadline
- Define duration in minutes

**[Screen: Exam key entry screen]**

"Security is built-in. Every exam has a 6-digit exam key. Students cannot access questions without this key. Share it only when the exam begins - via announcement, in class, or through messaging."

#### Automatic Grading

**[Screen: Grading algorithm visualization]**

"This is where magic happens. The moment a student submits their exam, the system:
1. Compares their answers to correct answers
2. Calculates marks for each question
3. Sums up the total score
4. Computes percentage
5. Displays results instantly

No manual grading. No delays. No human error."

### SECTION 4: How It Works - Quick Walkthrough (6:30 - 8:30)

**[Screen: Animated workflow from start to finish]**

**Narrator:**
"Let's see the complete journey of an online exam from creation to results:"

**[Visual: Timeline animation]**

**STEP 1 - Preparation**
"A teacher creates an exam for 'Mathematics Chapter 5' scheduled for next Monday at 10 AM, duration 60 minutes."

**STEP 2 - Adding Questions**
"They add 20 questions from the question bank - mix of easy, medium, and hard - totaling 50 marks."

**STEP 3 - Security Setup**
"They set exam key as 245678 and announce the exam to students."

**STEP 4 - Exam Day**
"Monday arrives. At 10 AM, students open their app, navigate to Online Exams, and enter the exam key."

**STEP 5 - Taking the Exam**
"The timer starts. Students read questions, select answers, navigate between questions, and watch the countdown."

**STEP 6 - Submission**
"At 10:55, students review their answers and submit. The exam auto-submits at 11 AM for anyone who hasn't manually submitted."

**STEP 7 - Instant Results**
"Immediately after submission, students see their scores. The teacher sees all results in their dashboard."

**STEP 8 - Analysis**
"Teachers analyze performance, identify difficult questions, and plan future lessons accordingly."
