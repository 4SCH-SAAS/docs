## [01:30-03:00] Creating Assignments (90 sec)

**[VISUAL]**
- Teacher dashboard with "Create Assignment" button
- Assignment creation form with fields:
  - Assignment Title (e.g., "Chapter 3: Forces - Practice Problems")
  - Description/Instructions (rich text editor with formatting)
  - Subject (dropdown)
  - Class/Section selection (multi-select)
  - Assignment Type (Homework, Classwork, Project, Essay, etc.)
  - Instructions text area
  - Attachments section (drag-drop or file upload)
  - Files uploaded showing: sample_questions.pdf, reference_guide.docx
  - Rubric section toggle (optional detailed grading criteria)
  - Due Date & Time picker
  - Allow Late Submission toggle with grace period
  - Max Attempts field (if resubmission allowed)
  - Points/Marks field (e.g., 50 points)
- Preview button showing how students will see it
- Create button with confirmation

**[VOICEOVER]:**  
"Creating an assignment starts with a clear title and detailed instructions. Use the rich text editor to format your instructions - bold important parts, use numbered or bulleted lists, add emojis for emphasis.

Select which classes receive this assignment. You can create one assignment for multiple classes, or if classes need different versions, create separate assignments. Choose the subject, helpful for organizing student workload.

Select assignment type: homework due after class, classwork due today, long-term projects, essays with detailed grading, or other custom types. Each type can have default settings.

Upload reference materials - sample problems, templates, reading materials. Students can download these immediately. Drag and drop multiple files, and they appear in a list.

Set the due date and time. By default, submissions after the deadline are rejected. If you want flexibility, enable 'Allow Late Submission' and set a grace period - say, two days late without penalty, or specify a reduced mark.

Optionally create a grading rubric here with criteria and point allocations. This ensures fair, consistent grading. Finally, preview how students will see the assignment, then create it. The system instantly notifies all students."

## [03:00-04:30] Student Submission Process (90 sec)

**[VISUAL]**
- Student mobile app showing assignment notification (red dot)
- Student taps notification, assignment details appear
- Reads instructions, downloads attachments
- Clicks "Submit Assignment" button
- Submission options appear:
  - Write text/answer directly in app
  - Upload file from device (single or multiple)
  - Paste link to Google Doc or web resource
  - Take photo/screenshot of handwritten work
- Student selects upload file option
- File picker shows multiple files selected
- Progress indicator during upload
- Submission confirmation showing:
  - Submission received time
  - Files submitted with checksums
  - Acknowledgment message
  - Can still submit again (if multiple attempts allowed)
- Notification: "Your teacher will review this by [date]"

**[VOICEOVER]:**  
"When a student receives an assignment, they tap the notification to view details. They can read the instructions, download reference materials, and submit their work.

Submissions are flexible. Students can type their answer directly in the app - useful for quick questions. They can upload files - documents, spreadsheets, presentations - whatever the assignment requires. They can paste links to Google Docs or Dropbox if they prefer collaborative tools.

For creative assignments, students can take photos of handwritten work or drawings and submit those. The system accepts diverse submission formats.

Once students tap 'Submit', their work uploads securely. They receive a confirmation with submission timestamp. If the teacher allows multiple attempts, students can resubmit improved versions before the deadline. Each submission is time-stamped and tracked separately.

Late submissions appear as 'Late' but still get recorded if the grace period allows. Students and parents see immediate confirmation that work was received."

**[VOICEOVER]:**  
"Teachers see all submissions in a dashboard. When students submit, a notification appears. Open the assignment to review all submissions.

For each submission, click the student's name to open their work. You can view files inline - PDFs display in a viewer, images show directly, and documents are previewable.

Add feedback: type comments directly in the feedback box. Format the text with bold, italic, and other styling. You can attach a corrected copy of the work or provide additional resources.

If you created a grading rubric, it appears here. Select the appropriate level for each criterion, and the system calculates the total marks automatically. For open-ended grading, just enter the marks in the total field.

Once you submit grades, students immediately receive notifications: 'Your assignment has been graded.' They can view feedback, marks, and any attachments you provided. This instant feedback loop encourages improvement."

Save frequently-used assignment formats as templates. Next term, just load the template, update dates, and it's ready for students. This consistency helps students know what to expect.

Link assignments to your timetable, so students see when they're due in their schedule. Connect assignments to chapters in your study materials or learning objectives. This integration helps students understand how assignments support their learning.

Advanced analytics show correlations: Do students who submit assignments on time perform better on exams? This data helps you refine teaching strategies.

If a student accidentally submits the wrong file, they can request to undo the submission. You review and approve - they get another chance to submit the correct file."
