# Offline Exams - Admin & Teacher Guide

**Video Duration:** 14-16 minutes  
**Target Audience:** Administrators and Teachers  
**Difficulty Level:** Beginner to Intermediate  
**Prerequisites:** Basic 4SCH login and navigation

---

## Video Objectives

By the end of this video, administrators and teachers will be able to:
1. Create offline exams and timetables (admins)
2. Enter and manage student marks (teachers)
3. Publish and manage results (admins)
4. Handle common scenarios and issues

---

## Script

### INTRO (0:00 - 0:45)

**[Screen: Admin and teacher at their desks]**

**Narrator:**
"Welcome administrators and teachers! This tutorial will guide you through the complete process of managing offline exams in 4SCH. Admins, you'll learn how to create exams and timetables. Teachers, you'll master the mark entry process. And we'll cover best practices to make exam management smooth and efficient. Let's get started!"

### PART 1: FOR ADMINISTRATORS (0:45 - 8:00)

#### Section 1: Creating an Exam (0:45 - 2:30)

**[Screen: Login and navigate to dashboard]**

**Narrator:**
"First, let's create an offline exam. Login to your 4SCH admin account and navigate to the main dashboard."

**[Screen: Exams menu → Offline Exams]**

"Click on **Exams** in the menu, then select **Offline Exams**. You'll see a list of existing exams if any."

**[Screen: Create Offline Exam button]**

"Click the **Create Offline Exam** button."

**[Screen: Exam creation form]**

"Now you'll see the exam creation form. Let's fill it in step by step."

**Field 1: Exam Name**
"Give your exam a clear, descriptive name. Instead of 'Exam 1', use something specific like 'First Term Examination - March 2025' or 'Mid-Term Test - Class 10'."

**Field 2: Class**
"Select the class for this exam. Let's choose 'Class 10'."

**Field 3: Session Year**
"This is usually auto-selected to the current academic year - 2024-25."

**Field 4: Description (Optional)**
"Add any additional details - 'First major exam of the term covering all subjects taught in first semester.'"

**Field 5: Start Date**
"When do the exams begin? Let me set March 15, 2025."

**[Screen: Calendar picker demonstration]**

**Field 6: End Date**
"When do exams finish? I'll set March 28, 2025 - giving us about 2 weeks for the complete exam period."

**Field 7: Publish**
"Should results be visible to students right away? Set this to 'No' initially. We'll publish results only after all marks are entered and verified."

**[Screen: Click Submit]**

"Review all details and click **Submit**. Your exam structure is now created!"

**[Screen: Success message]**

"Great! Now we need to add the timetable."

**[Screen: Exam list, click on newly created exam]**

**Narrator:**

**[Screen: Timetable creation interface]**

"Now we add each subject to the timetable. Let me show you how."

**Adding First Subject - Mathematics**

**[Screen: Form with fields visible]**

"**Subject:** From the dropdown, select 'Mathematics'

**Date:** Click the calendar - I'll choose March 15, 2025

**Start Time:** When does this exam begin? Let's say 9:00 AM

**End Time:** When does it end? Mathematics needs 3 hours, so 12:00 PM

**Total Marks:** Maximum marks for this subject - 100

**Passing Marks:** Minimum marks to pass - typically 35 or 40. I'll use 35."

**[Screen: Click Add or Save]**

"Click **Add** and Mathematics is now in your timetable!"

**[Screen: Mathematics added to list]**

**Adding More Subjects**

**Narrator:**
"Repeat this process for all subjects. Let me add a few more quickly."

**[Screen: Quick montage of adding subjects]**

"English: March 17, 9 AM - 11:30 AM, 80 marks, passing 28
Science: March 19, 9 AM - 12 PM, 100 marks, passing 35
Social Science: March 21, 9 AM - 11 AM, 80 marks, passing 28
Computer Science: March 24, 10 AM - 12 PM, 50 marks, passing 18"

**[Screen: Complete timetable view]**

"Perfect! Your timetable is complete. Students can now see their exam schedule."

**[Screen: Highlight important points]**

**Pro Tips:**
✓ Space out exams - don't schedule back-to-back
✓ Put difficult subjects first (students are fresher)
✓ Allow time for evaluation between subjects
✓ Double-check dates don't overlap
✓ Ensure passing marks are reasonable (typically 35-40%)

**[Screen: After exams are conducted]**

**Narrator:**
"Once exams are conducted and teachers are evaluating papers, you need to monitor mark entry progress."

**[Screen: Open exam → View marks]**

**[Screen: Subject-wise mark entry status]**

"You'll see a list of subjects showing:
- Which subjects have marks entered

"If marks are missing:
1. Check which teacher is assigned
2. Send a reminder via 4SCH messaging
3. Set a deadline for mark entry
4. Follow up personally if needed"

**[Screen: Validation check]**

"Before publishing, verify:
✓ All subjects have marks for all students
✓ No marks exceed total marks
✓ Passing marks are correctly calculated
✓ Absences are marked appropriately"

#### Section 4: Publishing Results (6:30 - 8:00)

**[Screen: Exam details with Publish button]**

**Narrator:**
"When all marks are entered and verified, it's time to publish results."

**[Screen: Pre-publication checklist]**

"Before clicking publish, final checks:
1. All marks entered - no blanks
2. Calculate sample results manually to verify
3. Check for any outliers (extremely high or low marks)
4. Confirm with teachers that evaluation is complete
5. Get principal's approval if required"

"Click **Publish Results**."

**[Screen: Confirmation dialog]**

"You'll see a confirmation: 'Are you sure you want to publish results? Students and parents will be able to view them.'"

**[Screen: Click Confirm]**

**[Screen: Student notification animation]**

"Students and parents receive notifications. Results are visible on their apps and portals immediately."

**[Screen: Unpublish option]**

"Need to make corrections? Click **Unpublish Results**. This hides results from students while you make edits. Remember to republish when done!"

**[Screen: Best practices callout]**

**Best Practices:**
✓ Publish during school hours (easier to handle queries)
✓ Announce publication date in advance
✓ Be available for questions after publishing
✓ Have teacher contacts ready for mark verification
✓ Export results as backup before publishing

**[Screen: Student list appears]**

"A list of all students in the class appears with columns for:

#### Section 4: Best Practices for Teachers (13:15 - 14:30)

**[Screen: Best practices checklist]**

**Narrator:**
"Let me share some best practices to make your life easier."

**Before Exams:**
✓ Review the timetable for accuracy
✓ Prepare your question paper well in advance
✓ Plan your evaluation strategy
✓ Prepare marking scheme for consistency

**During Evaluation:**
✓ Evaluate papers within 3-5 days while fresh
✓ Use a marking scheme for fairness
✓ Keep a physical record as backup
✓ Note any exceptional cases
✓ Write clear remarks on papers

**During Mark Entry:**
✓ Enter marks within 1 week of evaluation
✓ Double-check entries before saving
✓ Use Tab key for speed
✓ Add comments for special cases
✓ Save frequently (after every 10-15 students)

**After Entry:**
✓ Review your entered marks once
✓ Check class average (should be realistic)
✓ Verify no student shows 0 unless absent
✓ Inform admin that your marks are ready
✓ Be available for any queries

**[Screen: Common mistakes to avoid]**

**Avoid These Mistakes:**
❌ Waiting too long to enter marks (memory fades)
❌ Entering marks without double-checking
❌ Not adding comments for absences
❌ Exceeding total marks (system will reject anyway)
❌ Not saving - you might lose data!
