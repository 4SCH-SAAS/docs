# Video Script: Lessons & Topics

**Duration:** 7 minutes
**Target Audience:** Teachers (primary), with sections useful for School Admins and Students
**Learning Objectives:**
- Create a lesson scoped to one or more class sections and a subject
- Attach the right kind of material — File Upload, Video Upload, YouTube Link, or Other Link
- Understand the relationship between Lessons and Topics
- Know how students see and consume lessons in the web portal and mobile app
- Adopt sensible habits for keeping a lesson library tidy across a school term

- Click **Add Lesson** → form opens with four fields:
  - **Name** — types "Chapter 3: The Water Cycle"
  - **Description** — types "Understand the four stages of the water cycle and how each transitions to the next"
  - **Class Section** — multi-select dropdown, ticks JSS 1A, JSS 1B, JSS 1C
  - **Subject** — picks "Basic Science"
- Click **Save** → success toast → page redirects to the lesson's detail page (still empty, waiting for attachments)

**[VOICEOVER]:**
"To create a lesson, open **Lessons** in the sidebar and click **Add Lesson**. Fill in the form:

- **Name** is a clear, learner-friendly title — 'Chapter 3: The Water Cycle' works better than 'Lesson 12'.
- **Description** is a short summary or learning objective that appears on the lesson card so students know what's inside before they click.
- **Class Section** is multi-select — if two or three sections cover the same content, tick them all and create the lesson once.
- **Subject** is which subject this lesson counts under.

Click **Save**, and you'll land on the lesson's detail page — empty for now, waiting for you to attach materials."

## [02:15-04:00] Attaching Materials (105 sec)

**[VISUAL]**
- On the lesson detail page → **Add Attachment** button
- Click → **Type** dropdown shows four options:
  - File Upload
  - Video Upload
  - YouTube Link
  - Other Link
- Demo each type:
  1. **File Upload** — name "Lecture slides", file upload picker → select water-cycle-slides.pdf → Save → row appears with PDF icon and download arrow
  2. **YouTube Link** — name "Bill Nye on the Water Cycle", link field → paste `https://www.youtube.com/watch?v=...` → 4SCH validates URL → thumbnail auto-suggested → Save → row appears with YouTube logo
  3. **Other Link** — name "Khan Academy: Hydrologic Cycle", URL → paste link → upload a thumbnail → Save → row appears with link icon
- Show four-row list at end with mixed types

**[VOICEOVER]:**
"Each lesson can have one or more attachments. 4SCH supports four types — pick the one that fits the material you're sharing.

**File Upload** is for documents you want students to download — your slide deck, a worksheet, a printable handout.

**Video Upload** is for short videos you've recorded yourself. Try to keep these small — for anything longer than a few minutes, YouTube is a much better option.

**YouTube Link** is the most powerful option. Paste a regular YouTube URL — 4SCH validates that it really is YouTube — and students get the video embedded in their lesson view, no upload limits, no streaming costs.

**Other Link** is for anything else — Khan Academy, a Google Drive folder, a website. Add a clear name and a thumbnail so the link doesn't look anonymous.

For every attachment, give it a short name so students know what they're clicking. The maximum file size is set platform-wide — typically a few megabytes per file — and the form blocks anything too large or in the wrong format with a clear error message, so you can resize or convert before retrying."

**[ON-SCREEN TEXT]**
- "Four types: File · Video · YouTube · Other Link"
- "Always name your attachments"
- "Prefer YouTube for video where you can"

**[VISUAL]**
- Class Subjects page → click into one subject → "Topics" tab → list of topics with completion checkboxes
- Animation: as new lessons are created, related topics appear here automatically
- Principal-view diagram: Topics list → green ticks for completed → progress percentage

**[VOICEOVER]:**
"You'll see the word **Topic** in a few places in 4SCH — under **Class Subjects → Topics**, and on student timetables. Topics are the syllabus headings that lessons relate to. They're managed alongside lessons, so creating a lesson can implicitly create or link to its matching topic. Most teachers don't need to think about topics separately — focus on lessons and the topic side takes care of itself.

The Topics list does become useful if your school uses a detailed syllabus tracker — you can tick off completed topics so the principal can see progress at a glance."

## [05:30-06:30] Practical Tips (60 sec)

**[VISUAL]** Tip cards appearing one at a time:
- 📅 **One lesson per class period** — keeps the list scannable for students
- 📺 **Use YouTube where you can** — faster, more reliable, no upload limits
- 🖼️ **Add a thumbnail** to every video and link — clean lesson page
- 🔁 **Tick multiple sections** when content is shared — no duplication

**[VOICEOVER]:**
"Four habits that make the Lessons module shine.

One — aim for one lesson per scheduled class period. That keeps the list scannable for students and lets them find 'yesterday's lesson' without scrolling forever.

Two — use YouTube Link attachments where you can. They're faster, more reliable, and free of upload limits, so prefer them over uploading large video files.

Three — add a thumbnail to every video and link. It makes the lesson page feel tidy. For YouTube links, download the video's cover image once and re-use it.

Four — when two or more class sections cover the same content, create the lesson once and tick all the relevant Class Section checkboxes. There's no need to duplicate work."

**[ON-SCREEN TEXT]**
- "One lesson per period"

- "Tick all relevant sections"
