## [01:15-02:30] Mobile Attendance Marking (75 sec)

**[VISUAL]**
- Teacher opens 4SCH app on mobile
- Dashboard shows "Mark Attendance" button
- Select class (dropdown showing current class)
- Student list appears with photos and names
- Teacher scrolls through students
- Tap each name: presence icon changes from grey to green (present)
- Swipe or long-press for options: Absent, Late, On Leave
- Confirmation dialog appears
- Students marked as absent show in red with absence reason dropdown
- Complete and submit button with sync indicator

**[VOICEOVER]:**  
"Let's mark attendance on mobile. Open 4SCH and tap 'Mark Attendance'. Select the current class - the app knows your schedule.

You'll see the complete student roster with photos. For each student present, tap their name. It turns green. If a student is absent, tap and select 'Absent'. If they're late, choose 'Late' and the system records the time.

For students on approved leave, select 'On Leave' - the system won't count this against their attendance.

Notice the empty reason field appears for absences. You can optionally note why - 'Sick', 'Family Emergency', etc. Once you've marked everyone, review the summary and tap 'Submit'. The system syncs with the main database instantly, even on slow connections - it queues the update if needed."

## [05:00-06:15] Policies, Alerts & Parent Communication (75 sec)

**[VISUAL]**
- Settings > Attendance Policies screen

- Late arrival threshold (e.g., after 9:30 AM)
- Consecutive absence alert trigger (e.g., 3 consecutive days)
- Alert recipient configuration (Parents, Guardians, Admins)
- Enable/disable automatic notifications toggle
- Preview notification template

**[VOICEOVER]:**  
"Set up attendance policies to automate alerts. Define minimum attendance requirements - usually 80%. The system will flag students falling below this threshold.

Set a late arrival time - anything after 9:30 AM might be considered late. Configure alerts for consecutive absences. If a student misses three days in a row, automatically notify parents and administrators.

Choose who receives alerts: parents, guardians, both, or just administrators. You can customize the notification message. By default, when a student is marked absent, the parent receives an instant notification via the app and SMS.

These automated alerts help catch attendance issues early. Parents see patterns developing and can intervene before it becomes a serious problem."
