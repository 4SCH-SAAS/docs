## Resolution & Aspect Ratio

### Primary Format
- **Resolution:** 1920 x 1080 pixels (Full HD/1080p)
- **Frame Rate:** 30 fps (NTSC regions) or 25 fps (PAL regions)
- **Aspect Ratio:** 16:9 (standard widescreen)
- **Codec:** H.264 (MP4 container for web)

### Mobile Optimization
- **Resolution:** 1080 x 1920 pixels (vertical)
- **Frame Rate:** 30 fps
- **File Size:** Optimized for mobile delivery (max 500 MB for 10-minute video)

### Screen Recording Specifications
- **Minimum Resolution:** 1920 x 1080 at 100% zoom
- **Display Scaling:** Ensure all text is readable (minimum 12pt font in 1080p)
- **Color Depth:** 24-bit (true color)
- **Background:** Minimize distracting backgrounds; use solid colors or neutral desktop

### Subtitle/Caption Area
- **Safe Area:** Keep all on-screen text within 90% of the frame to avoid cutting off on older displays
- **Text Size:** Minimum 48px at 1080p (scales proportionally)
- **Text Placement:** Avoid overlapping voiceover or important visual content

## Branding & Visual Identity

### Color Palette

**Primary Colors:**
- 4SCH Blue: `#0066CC` (primary CTA, highlights)
- Dark Gray: `#333333` (text, overlays)
- White: `#FFFFFF` (backgrounds, contrast)

**Secondary Colors:**
- Light Blue: `#E6F2FF` (backgrounds, accent)
- Success Green: `#28A745` (confirmations, checkmarks)
- Warning Orange: `#FF9800` (alerts, cautions)
- Error Red: `#DC3545` (errors, important warnings)

### Logo Usage
- **4SCH Logo:** Must appear in opening sequence (2-3 seconds)
- **Logo Size:** Minimum 200px width when displayed solo
- **Placement:** Top-left or center (following safe area guidelines)
- **Transparency:** Logo should have clear background or inverse variant for dark overlays
- **Animation:** Fade-in/out or subtle zoom acceptable; no spinning or distracting animations

### Typography

**Headlines (On-Screen Text):**
- Font: Sans-serif (Helvetica, Arial, or Segoe UI)
- Size: 48-72px (1080p video)
- Weight: Bold (600-700)
- Color: 4SCH Blue or Dark Gray on light backgrounds; White on dark backgrounds
- Line Height: 1.2
- Letter Spacing: Normal or slightly increased for readability

**Body Text (Captions, Labels):**
- Font: Sans-serif (Helvetica, Arial, or Segoe UI)
- Size: 32-40px (1080p video)
- Weight: Regular (400)
- Color: Dark Gray or White (high contrast)
- Line Height: 1.4

**Captions:**
- Font: San-serif, high contrast
- Size: 44-48px minimum at 1080p
- Background: Semi-transparent black bar (for legibility)
- Style: Sentence case (not all caps unless original is uppercase)

### Visual Elements

**Overlays & Graphics:**
- Use 4SCH branding colors consistently
- Keep animations smooth and professional (200-500ms transitions)
- Avoid flashing (no more than 3 flashes per second per WCAG guidelines)
- Lower opacity for non-essential graphics (60-80% opacity)

**Icons:**
- Use consistent icon style throughout (Material Design, FontAwesome, or custom)
- Maintain consistent sizing (scale proportionally)
- Ensure icons contrast with background (minimum 4.5:1 ratio)

**Watermark:**
- Optional: 4SCH watermark in lower-right corner
- Size: 5-10% of frame width
- Opacity: 30-50% (non-intrusive)

## Accessibility Standards

### Captions & Subtitles

**All videos MUST include captions:**
- Captions for all dialogue (voiceover, interviews, on-screen speakers)
- Labels for important sound effects `[upbeat music playing]`
- Speaker identification: `[VOICEOVER]:` or `[Teacher]:` 
- Format: SRT, WebVTT, or burned-in captions (must use one)

**Caption Timing:**
- Display time: Minimum 1.5 seconds for short text (5 words or less)
- Display time: 0.3 seconds per word for longer text
- Avoid overlapping text on same line
- Synchronize precisely with audio (±200ms accuracy)

**Caption Content:**
- Use proper grammar and punctuation
- Spell out numbers and acronyms on first use
- Use `[Pause]` for significant silences
- Include music descriptions: `[upbeat music fades]`

### Audio Description (AD)

**For Complex Visual Content:**
- Provide optional audio description track for users with vision impairments
- Describe key visual changes, transitions, and on-screen text
- Integrate naturally between dialogue or use separate stereo track
- Total AD length: Should not exceed 10% of video length

### Keyboard Navigation
- All interactive elements must have keyboard shortcuts (for web versions)
- No content should be keyboard-inaccessible

### Color Contrast
- Minimum contrast ratio: 4.5:1 for text/graphics on backgrounds (WCAG AA)
- Enhanced contrast: 7:1 recommended (WCAG AAA)
- Don't use color alone to convey information (pair with text or patterns)

### Animation & Motion
- No auto-playing videos with sound
- Animations should be stoppable or complete within 5 seconds
- Avoid flashing or rapidly changing content (no more than 3 flashes per second)

### Transcripts
- Provide full text transcript for every video
- Include speaker labels, sound descriptions, and visual descriptions
- Make transcripts searchable and linkable
- Format: PDF or HTML for accessibility

## Audio Specifications

### Voiceover Standards

**Recording Environment:**
- Quiet recording space (minimal background noise, target: -40dB or quieter)
- Use lavalier microphone or condenser microphone (no built-in laptop mics)
- Consistent distance from microphone (4-6 inches optimal)
- Avoid echo chambers; use soft furnishings to reduce reverb

**Audio Quality:**
- Sample Rate: 48 kHz (broadcast standard)
- Bit Depth: 24-bit (professional quality)
- Bitrate: 320 kbps for MP3 export; 128 kbps minimum for streaming
- Format: WAV or AIFF for editing; MP3 or AAC for final delivery

**Voiceover Delivery:**
- Speaking Rate: 120-150 words per minute (clear, unhurried)
- Tone: Conversational, friendly, professional (matching video tone)
- Enunciation: Clear pronunciation; avoid mumbling
- Emphasis: Natural emphasis on key points (avoid robotic delivery)
- Breathing: Pause for breath between sentences; remove loud breath sounds in editing

### Background Music

**Music Selection:**
- Royalty-free music (purchased license or Creative Commons)
- Recommend: Epidemic Sound, Artlist, or YouTube Audio Library
- Tempo: 80-120 BPM for most instructional content
- Mood: Upbeat but not distracting for tutorial content; energetic for intros/outros
- Genre: Modern electronic, corporate, or contemporary pop

**Music Levels:**
- Background music: -15 to -20 dB (significantly quieter than voiceover)
- Intro/Outro music: -5 to -10 dB (more prominent)
- Music should fade under voiceover (crossfade 1-2 seconds)
- Avoid abrupt starts/stops; use fade-in/out (minimum 0.5 seconds)

### Sound Effects

**Selection:**
- Use sparingly and purposefully (don't overload with sounds)
- Match video content (UI sounds for system screens, etc.)
- Royalty-free sources: Freesound, Zapsplat, or purchased effects
- Recommend: Subtle UI sounds (-25 to -20 dB)

**Timing:**
- Sync exactly with on-screen action (±100ms)
- Duration: Keep effects short (0.5-2 seconds maximum)
- Avoid sudden loud sounds (can startle viewers)

### Audio Mixing

**Final Mix Loudness:**
- Target: -23 LUFS (broadcast loudness standard)
- Maximum Peak Level: -1 dB (prevent clipping)
- Dynamic Range: Maintain 6-10 dB between quiet and loud sections
- Check on multiple speakers (small phone speakers to large monitors)

**Testing:**
- Listen on laptop speakers, phone speakers, and headphones
- Check audio sync with video (no drift)
- Verify music and SFX don't drown out voiceover
- Test that captions match audio timing

## Video Structure & Format

### Standard Video Length
- **Intro Series:** 5-8 minutes
- **Role-Based Guides:** 8-12 minutes
- **Feature Deep Dives:** 10-15 minutes
- **Support/FAQ:** 8-10 minutes
- **Absolute Maximum:** 20 minutes (longer videos lose engagement)

### Video Structure Template

```
[00:00-00:10] Intro
- 4SCH logo animation
- Video title on screen
- Engaging hook statement

[Opening minutes] Context & Overview
- Set expectations
- Explain what viewers will learn
- Establish relevance

[Middle section] Main Content
- Core instruction (break into logical segments)
- Screen recordings with overlays
- On-screen text for key points
- Pace: Average 2-4 minutes per major topic

[Closing] Summary & Next Steps
- Recap key learning points
- Call to action (related videos, next steps)
- Encourage practice/exploration

[00:XX-00:XX] Outro
- 4SCH branding/logo
- Credits (if applicable)
- End screen with related videos
```

### Scene Composition

**Desktop/Application Recording:**
- Zoom to 100-120% to ensure readability
- Use high-contrast cursor (recommended: white with black outline)
- Highlight important UI elements with circles, arrows, or color overlays
- Keep editing workspace clean (hide unnecessary windows/toolbars)

**Pacing:**
- Screen recordings: Allow 3-5 seconds for viewers to read on-screen text
- Animations/transitions: 0.5-1 second duration (not too fast/slow)
- Silence: Minimal; use background music to fill quiet moments
- Quick cuts between scenes: Keep editing brisk to maintain engagement

### Transitions

**Recommended Transitions:**
- Fade (0.3-0.5 seconds) - most common, least distracting
- Cut (instant) - for fast-paced content
- Dissolve (0.5 seconds) - between related scenes
- Wipe (0.5 seconds) - directional scene changes

**Transition Rules:**
- Use consistent transitions throughout video (not mix random types)
- Avoid overuse (maximum 2-3 per minute)
- Transition should not distract from content

## Script Writing Standards

### Voice & Tone

**Professional Instructional Tone:**
- Conversational but authoritative
- Clear, jargon-free (or define terms)
- Encouraging and supportive (especially for challenges)
- Pacing: 120-150 words per minute

### Script Format

**Required Elements in Script:**
```
# Video Title
**Duration:** X minutes
**Target Audience:** [specific roles]
**Learning Objectives:**
- Objective 1
- Objective 2
- Objective 3

## [MM:SS-MM:SS] Section Title (duration)

**[VISUAL]** What appears on screen
**[MUSIC]** Background audio (if relevant)
**[VOICEOVER]:** 
"Spoken text here..."

**[ON-SCREEN TEXT]**
- "Text element 1"
- "Text element 2"

### SEO Metadata
**Keywords:** [relevant terms]
**Tags:** #tag1 #tag2
```

### Language & Clarity

- Use simple, direct language (avoid jargon unless necessary)
- Define technical terms on first use
- Use active voice ("Teachers mark attendance" vs. "Attendance is marked by teachers")
- Keep sentences concise (under 20 words average)
- Break complex ideas into smaller segments

### Inclusivity

- Use gender-neutral pronouns (they/them) or mix examples
- Consider diverse school contexts (rural, urban, various economic levels)
- Use diverse names and examples in demonstrations
- Acknowledge different learning styles and speeds

## Editing & Post-Production

### Video Editing Software
- Recommended: Adobe Premiere Pro, DaVinci Resolve, Final Cut Pro
- Minimum requirement: Support for 1080p H.264, subtitles, color grading
- Version control: Save timestamped versions during editing

### Color Grading
- Consistent color temperature across all scenes
- Maintain skin tones (if featuring people): avoid green/blue casting
- Screen recordings: Ensure sufficient brightness (not too dim)
- Gamma: Consistent across all footage

### Screen Recording Software
- OBS Studio (free, open-source)
- ScreenFlow (Mac)
- Camtasia
- Adobe Capture
- Settings: Minimum 1920x1080 resolution, 30 fps

### Quality Checklist

Before exporting final version, verify:
- [ ] All dialogue is clearly audible without distortion
- [ ] Voiceover levels are consistent (no sudden loud/quiet sections)
- [ ] Captions are synced and readable
- [ ] Text on screen is large enough and has sufficient contrast
- [ ] Transitions are smooth and purposeful
- [ ] No dead air or long silences
- [ ] Color is consistent and professional
- [ ] No visual glitches or artifacts
- [ ] Pacing is appropriate (not too fast/slow)
- [ ] All branding is consistent (colors, fonts, logos)
- [ ] Logo appears in intro and outro
- [ ] Video length is appropriate for content

## File Delivery Requirements

### Delivery Formats

**For Web Streaming:**
- Format: MP4 (H.264 video + AAC audio)
- Resolution: 1920 x 1080 (1080p)
- Bitrate: 5-8 Mbps video, 128 kbps audio
- File size: Typically 100-300 MB for 10-minute video

**For Mobile/Low-Bandwidth:**
- Format: MP4 (H.264 video + AAC audio)
- Resolution: 1280 x 720 (720p)
- Bitrate: 2-4 Mbps video, 96 kbps audio
- File size: 50-150 MB for 10-minute video

**For Archive/Editing:**
- Format: ProRes 422 (Apple) or DNxHD (Avid)
- Resolution: 1920 x 1080
- Bitrate: Mezzanine quality (lossless or high-quality lossy)
- Separate audio files (WAV, 48 kHz, 24-bit)

### Captions & Subtitles

**File Formats:**
- WebVTT (.vtt) - preferred for web
- SRT (.srt) - compatible with most platforms
- Burned-in captions - embedded in video file (less flexible, not preferred)

**Delivery:**
- Separate caption files (not burned-in) for maximum flexibility
- One caption file per language
- UTF-8 encoding

### Metadata & Documentation

**Required with Each Submission:**
- Video title and description (2-3 sentences)
- Learning objectives (3-5 bullet points)
- Target audience/role
- Keywords and tags (5-10)
- Thumbnail image (1280 x 720 pixels, high contrast)
- Chapter markers (if applicable)

**Example Metadata:**
```json
{
  "title": "User Roles Explained",
  "duration_seconds": 480,
  "description": "Learn about the 7 user roles in 4SCH and understand what each role can do.",
  "target_audience": ["New Users", "System Administrators"],
  "learning_objectives": [
    "Understand the 7 primary user roles",
    "Learn permissions for each role",
    "Identify your role"
  ],
  "keywords": ["roles", "permissions", "access control"],
  "tags": ["#Roles", "#Permissions", "#Introduction"]
}
```

### File Organization

```
video-tutorials/
├── production-assets/
│   ├── project-files/          [Adobe, DaVinci, FCP files]
│   ├── source-footage/         [Raw recordings, interviews]
│   ├── graphics/               [PNGs, SVGs, templates]
│   └── audio/                  [Voiceovers, music, SFX]
├── scripts/                    [Markdown scripts]
├── metadata/                   [JSON metadata files]
├── finished-videos/
│   ├── 1080p/                 [Full HD versions]
│   ├── 720p/                  [Mobile-optimized]
│   └── captions/              [VTT/SRT files]
└── thumbnails/                [JPEG thumbnails]
```

### Quality Assurance

**Internal Review Checklist:**
- Content accuracy verified against product
- All text is spell-checked
- Audio is at consistent levels
- Captions are complete and synced
- Visual elements are on-brand
- No sensitive information displayed
- Links in description work correctly
- Video plays without artifacts

**Final Delivery:**
- All files properly named with version numbers
- Metadata JSON completed
- Captions file included
- Thumbnail generated
- README documenting any special requirements

## Publishing & Distribution

### Platform-Specific Requirements

**YouTube:**
- Title: 60 characters max (include main keywords)
- Description: First 2-3 lines visible; include timestamps for chapters
- Thumbnail: 1280 x 720 pixels, high contrast, text-readable at small sizes
- Tags: 10-15 relevant tags
- Category: "Education" or "Howto & Style"

**Internal LMS/Website:**
- Ensure metadata JSON is complete
- Captions essential for accessibility
- Consider lower bitrate version for slow connections
- Provide downloadable transcript

## Maintenance & Updates

### Version Control

When updating videos:
- Keep original with version 1.0 name
- New versions: increment (1.1, 1.2, 2.0)
- Document changes in metadata
- Update publish date
- Replace old version on platforms or archive clearly

### Outdated Content

- Review videos quarterly for outdated information
- Update captions/metadata if UI changes
- Re-record entire video if major functionality changes
- Note update date in description
